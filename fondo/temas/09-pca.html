PCA rota los ejes hacia las direcciones de mayor varianza y descarta las últimas. Cálculo real: centrar y una SVD. Nada de iteraciones ni gradiente; resultado exacto y determinista (salvo el signo).

Mapa del cálculo

Paso a paso: 2D → 1D

Cinco puntos: (2, 1), (3, 4), (4, 3), (5, 6), (6, 5).

  1. 1 · Mediaμ = (20/5, 19/5) = (4, 3.8)

    Se guarda: en producción cada x nuevo se centra con esta μ de train.

  2. 2 · CentrarXc = (−2, −2.8), (−1, 0.2), (0, −0.8), (1, 2.2), (2, 1.2)

    Sin centrar, la primera dirección apunta hacia la media, no hacia la dispersión.

  3. 3 · SVDσ = (4.763, 1.455)v₁ = (0.619, 0.785), v₂ = (0.785, −0.619)

    Mismos vectores que eig de C = [[2.5, 2.5], [2.5, 3.7]]. v₁ ⟂ v₂.

  4. 4 · Proyectarz = Xc v₁ = (−3.44, −0.46, −0.63, 2.35, 2.18)

    Cada punto = un número. Proyección ortogonal: línea punteada ⟂ v₁.

  5. 5 · Reconstruirx̂ = z v₁ᵀ + μ, Σ‖x − x̂‖² = 2.116 = σ₂²

    Error total = varianza tirada. Base de detección de anomalías: error alto = punto atípico.

  6. 6 · Varianza explicadaλ = σ² / 4 = (5.671, 0.529) → (91.5 %, 8.5 %)

    Un eje conserva 91.5 % de la varianza. Suma de λ = traza de C = 2.5 + 3.7.

Elegir k: varianza acumulada

Fórmulas clave

Objetivo
v₁ = argmax‖v‖=1 Var(Xc v) = argmax vᵀCv ⇒ Cv = λv
SVD ↔ covarianza
C = XcᵀXc/(n−1) = V (Σ²/(n−1)) Vᵀ ⇒ λⱼ = σⱼ²/(n−1)
Proyección
Z = Xc Vₖ = Uₖ Σₖ
Reconstrucción
X̂ = Z Vₖᵀ + μ; ‖Xc − ZVₖᵀ‖F² = Σj>k σⱼ² (óptimo de rango k, Eckart–Young)
Varianza explicada
rk = Σj≤k λⱼ / Σj λⱼ
Whitening
Zw = Xc Vₖ diag(λ)−1/2 (varianza 1 en cada componente)

En un sistema real

Uso típico
Comprimir embeddings antes de indexar, quitar colinealidad antes de regresión, visualizar (k = 2), detección de anomalías en sensores.
Monitorear
Error de reconstrucción medio y percentil 99 por día; varianza de cada z contra la de train.
Re-entrenar
Si cambia PCA cambia el espacio z: hay que re-entrenar o re-indexar todo lo que consume z. Versionar juntos.

Trampas

  • Sin escalar: una feature en metros y otra en milímetros; la de milímetros domina PC1 por unidades, no por información.
  • Signo arbitrario: v y −v son igual de válidos. Re-entrenar puede invertir ejes y romper modelos aguas abajo.
  • Fit con todo el dataset antes del split = fuga. Va dentro de Pipeline.
  • Máxima varianza ≠ máxima información para predecir: la señal útil puede vivir en un componente de poca varianza.
