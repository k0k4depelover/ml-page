Regularizar = sumar costo por tamaño de pesos. Modelo prefiere soluciones simples. L2 encoge todo proporcional. L1 resta constante y deja pesos en cero exacto: selecciona features.

Mapa del cálculo

Paso a paso: un paso con L2 y con L1

Tres pesos θ = (0.8, −0.05, 0.3), gradiente de datos g = (0.2, 0.1, −0.4), η = 0.5, λ = 0.2 ⇒ ηλ = 0.1.

  1. 1 · Pesos inicialesθ = (0.8, −0.05, 0.3)

    θ₂ casi nulo: feature poco útil.

  2. 2 · Paso de datosz = θ − 0.5·(0.2, 0.1, −0.4) = (0.7, −0.1, 0.5)

    Sin regularización, esto sería el nuevo θ.

  3. 3 · L2: weight decayθ = 0.9·θ − η g = (0.72 − 0.1, −0.045 − 0.05, 0.27 + 0.2)= (0.62, −0.095, 0.47)

    Factor 0.9 sobre θ: θ₁ pierde 0.08, θ₂ sólo 0.005. Peso grande paga más. θ₂ sigue vivo.

  4. 4 · L1: soft-threshold sobre zθ = sign(z)·max(|z| − 0.1, 0) = (0.6, 0, 0.4)

    Resta 0.1 a todos. |−0.1| ≤ 0.1 ⇒ θ₂ = 0 exacto.

  5. 5 · Lectura

    L2: todos sobreviven, más chicos. Útil con features correlacionadas: reparte peso.

    L1: pesos chicos mueren. Modelo disperso: menos features que calcular en producción.

Geometría: por qué L1 da ceros

Operador proximal: salida vs entrada

Lectura bayesiana

L2
Prior gaussiano θ ~ N(0, 1/λ). MAP = ridge. Creencia: muchos efectos pequeños.
L1
Prior Laplace con pico en 0. MAP = lasso. Creencia: pocos efectos reales.
Elastic net
λ(α‖θ‖₁ + (1−α)½‖θ‖²). Esparcidad de L1 + estabilidad de L2 con features correlacionadas.

Fórmulas clave

Ridge cerrado
θ* = (XᵀX + λI)⁻¹ Xᵀy (λI hace invertible aunque d > n)
Ridge vía SVD
θ* = Σj (sj / (sj² + λ)) ujᵀy · vj (encoge más las direcciones de poca varianza)
Weight decay
θ ← θ − η(g + λθ) = (1 − ηλ)θ − ηg
Proximal L1
proxηλ‖·‖₁(z) = argminθ ½‖θ − z‖² + ηλ‖θ‖₁ = sign(z)·max(|z| − ηλ, 0)
Lasso, condición de cero
θj = 0 ⇔ |xjᵀ(y − Xθ)| / n ≤ λ (correlación con residuo menor que λ)
λ máximo útil
λmax = maxj |xjᵀy| / n (por encima, todo θ = 0)

En un sistema real

Escalar primero
Penalización depende de unidades. Feature en metros vs milímetros recibe penalización distinta. Estandarizar siempre antes de ridge/lasso.
Redes neuronales
AdamW con λ ≈ 0.01–0.1, sin decay en sesgos ni LayerNorm. Otras regularizaciones: dropout, early stopping, data augmentation.
Monitorear
Brecha train vs validación. Brecha grande: subir λ. Ambas altas: bajar λ o modelo más expresivo.
Re-entrenar
Recalcular λ* cuando cambia mucho el volumen de datos: más datos ⇒ λ óptimo menor.

Trampas

  • Penalizar el sesgo (intercepto): desplaza predicciones hacia 0 sin motivo.
  • Lasso con features muy correlacionadas elige una al azar y descarta las otras; inestable entre re-entrenamientos. Elastic net.
  • Interpretar coeficientes de lasso como “importancia causal”: sólo dicen qué features bastan para predecir.
  • C en scikit-learn (LogisticRegression, SVC) = 1/λ: C grande = poca regularización.
