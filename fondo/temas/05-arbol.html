Árbol = búsqueda voraz. En cada nodo prueba todas las features y todos los umbrales, elige el corte que más baja la impureza, parte datos y repite en cada hijo. Nunca revisa decisiones pasadas.

Mapa del cálculo

Paso a paso: elegir el primer corte

Una feature (edad) y seis clientes. Clase 1 = compra. Criterio Gini.

  1. 1 · Ordenarx = (22, 25, 31, 38, 45, 52), y = (0, 0, 1, 0, 1, 1)

    Sólo importan cortes entre valores consecutivos distintos: m − 1 = 5 candidatos.

  2. 2 · Impureza del padreGini = 1 − Σ p_c² = 1 − 0.25 − 0.25 = 0.5

    0 = puro. 0.5 = máxima mezcla con 2 clases.

  3. 3 · Barrer umbralest = 28: L = [0, 0] → 0, R = [1, 0, 1, 1] → 1 − (1/4)² − (3/4)² = 0.375ponderado = (2/6)·0 + (4/6)·0.375 = 0.25 → Δ = 0.25

    Al mover el umbral, un punto pasa de R a L: actualizar conteos es O(1).

  4. 4 · Elegir el mejorΔ: 0.10, 0.25, 0.06, 0.25, 0.10 → empate 28 y 41.5

    Empate: se queda el primero (o aleatorio). Con d features se repite por cada una y gana el máximo global.

  5. 5 · Partiredad ≤ 28 → hoja clase 0 (pura)

    R sigue mezclado: el algoritmo se llama a sí mismo con esas 4 filas.

  6. 6 · RecursiónR: corte en 34.5 → [1] y [0, 1, 1]; luego 41.5 → [0] y [1, 1]

    Sin límite, el árbol memoriza: hojas de 1 muestra. max_depth y min_samples_leaf frenan.

Predicción: recorrer un camino

Fórmulas clave

Gini
G = 1 − Σc pc² (prob. de error al etiquetar al azar según p)
Entropía
H = −Σc pc log₂ pc (bits para codificar la clase)
Ganancia
Δ = I(padre) − (mL/m) I(L) − (mR/m) I(R)
Regresión
I = (1/m) Σ (yi − ȳ)²; hoja predice ȳ; barrido con sumas Σy y Σy² acumuladas
Poda costo-complejidad
Rα(T) = R(T) + α · |hojas(T)| (ccp_alpha en sklearn)
Importancia (MDI)
imp(j) = Σnodos que usan j (mnodo/n) · Δnodo (sesgada hacia features con muchos valores)

En un sistema real

Preprocesamiento
No necesita escalar (cortes son invariantes a transformaciones monótonas). Categóricas: one-hot o soporte nativo (LightGBM, sklearn ≥ 1.4 con HistGradientBoosting).
Faltantes
XGBoost/LightGBM aprenden dirección por defecto para NaN en cada nodo. sklearn clásico: imputar.
Monitorear
Distribución de hojas alcanzadas en producción vs entrenamiento: hoja que antes recibía 2% y ahora 20% = drift.
Re-entrenar
Árbol es inestable: datos ligeramente distintos ⇒ árbol muy distinto. Versionar y comparar reglas entre versiones.

Trampas

  • Árbol sin límite = 100% en train, mal en test. Siempre controlar profundidad u hojas mínimas.
  • Importancia MDI favorece features continuas o con muchas categorías (IDs). Preferir importancia por permutación.
  • Fronteras sólo paralelas a los ejes: relación diagonal x₁ ≈ x₂ necesita escalera de muchos cortes.
  • Clases desbalanceadas: usar class_weight o el árbol ignora la minoritaria.
