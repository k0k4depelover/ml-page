SVM busca la frontera con mayor margen. Formulación dual sólo usa productos punto entre muestras. Cambiar producto punto por kernel = frontera no lineal sin construir el espacio alto. Solución final depende sólo de vectores de soporte.

Mapa del cálculo

Geometría: margen y vectores de soporte

Paso a paso: kernel trick

Kernel polinómico grado 2 sin término constante: K(x, z) = (x·z)². Dos puntos x = (1, 2), z = (3, 1).

  1. 1 · Mapear xφ(x) = (x₁², √2·x₁x₂, x₂²) = (1, 2√2, 4)

    Espacio de todos los productos de grado 2. Ahí una frontera lineal es una cónica en el plano original.

  2. 2 · Mapear zφ(z) = (9, √2·3, 1) = (9, 4.243, 1)
  3. 3 · Producto en espacio alto⟨φ(x), φ(z)⟩ = 1·9 + 2√2·3√2 + 4·1 = 9 + 12 + 4 = 25
  4. 4 · Mismo número sin φ(x·z)² = (1·3 + 2·1)² = 5² = 25

    Dual sólo pide productos punto: kernel los da directo.

  5. 5 · Escalagrado 3, d = 100 ⇒ dim φ = C(102, 3) = 171 700

    Kernel sigue costando un producto punto de 100 entradas. RBF: dimensión infinita, costo O(d).

Fórmulas clave

Primal suave
minw,b,ξ ½‖w‖² + C Σ ξi s.a. yi(w·xi + b) ≥ 1 − ξi, ξi ≥ 0
Forma hinge
min (1/2C)‖w‖² + Σ max(0, 1 − yi f(xi)) (= regularización L2 + hinge)
Stationarity
∂/∂w = 0 ⇒ w = Σ αi yi xi; ∂/∂b = 0 ⇒ Σ αi yi = 0
KKT
αi = 0 ⇒ yif ≥ 1; 0 < αi < C ⇒ yif = 1; αi = C ⇒ yif ≤ 1
Sesgo
b = yk − Σi αi yi K(xi, xk) para cualquier SV con 0 < αk < C
Kernels
lineal x·z; polinómico (γ x·z + r)p; RBF exp(−γ‖x − z‖²)
Probabilidad (Platt)
P(y = 1 | x) = σ(A·f(x) + B), A, B ajustados con CV

En un sistema real

Escalar
Obligatorio: RBF usa distancias. Feature con rango 1000 domina a una con rango 1.
Tuning
Grid logarítmico en C y γ (10⁻³…10³) con CV. γ alto = cada SV influye sólo cerca: sobreajuste.
Monitorear
Fracción de predicciones con |f| < 1 (dentro del margen): si sube, datos nuevos caen en zona dudosa.

Trampas

  • decision_function no es probabilidad. probability=True ejecuta CV interna extra (lento) y puede contradecir a predict.
  • Kernel RBF con n = 10⁶: Gram de 10¹² entradas. Imposible; usar lineal, aproximaciones Nyström o boosting.
  • Muchos SVs (≈ n) = modelo no aprendió estructura; revisar C, γ y escalado.
  • Multiclase: sklearn SVC hace uno-contra-uno (K(K−1)/2 modelos); LinearSVC uno-contra-resto.
