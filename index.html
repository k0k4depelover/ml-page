Fundamentos

Varianza, covarianza y correlación

Cuánto se dispersa una variable y cuánto se mueven dos juntas. Es la materia prima de PCA, de las gaussianas y de la estandarización.

Para qué sirve

  • Describir la dispersión de una feature (varianza, desviación estándar).
  • Detectar relaciones lineales entre features (covarianza, Pearson r).
  • Estandarizar datos antes de KNN, SVM, PCA, regresión con regularización y redes.
  • Construir la matriz de covarianza que usan PCA, GMM y Naive Bayes.

Por qué funciona

La varianza es el promedio de las desviaciones al cuadrado respecto a la media. La covarianza hace lo mismo pero multiplica la desviación en x por la desviación en y: si cuando x está por encima de su media y también lo está, los productos son positivos y la covarianza crece. En la animación cada rectángulo es uno de esos productos: azul si suma, coral si resta. La correlación divide la covarianza entre ambas desviaciones para quitarle las unidades y dejarla en [−1, 1].

Fórmulas

Media
μ = (1/n) Σi xi
Varianza muestral
σ² = (1/(n−1)) Σi (xi − μ)²
Covarianza
cov(x, y) = (1/(n−1)) Σi (xi − μx)(yi − μy)
Pearson
r = cov(x, y) / (σx σy) ∈ [−1, 1]
Matriz de covarianza
C = (1/(n−1)) Xc⊤Xc, con Xc = X − μ
Z-score
z = (x − μ) / σ

Flujo de cálculo

  1. Calcular la media de cada columna.
  2. Restar la media a cada valor (centrar).
  3. Para varianza: elevar al cuadrado y promediar con n−1.
  4. Para covarianza: multiplicar desviaciones de dos columnas y promediar.
  5. Para correlación: dividir entre el producto de desviaciones estándar.
  6. Para la matriz completa: Xc⊤Xc / (n−1); la diagonal son las varianzas.

Hiperparámetros

ddof
1 para muestra (insesgado), 0 para población. NumPy usa 0 por defecto en var, Pandas 1.

Costo: O(n·d²) para la matriz de covarianza.

Cuidado con

  • Correlación cero no implica independencia: y = x² tiene r ≈ 0.
  • Pearson es sensible a outliers; Spearman (rangos) es la alternativa robusta.
  • Ajusta el escalador sólo con el set de entrenamiento y aplícalo al de prueba.

// Media, varianza, desviación, covarianza, correlación y z-score desde cero
#include <cmath>
#include <cstdio>
#include <vector>
using Vec = std::vector<double>;
using Mat = std::vector<Vec>;   // filas = muestras, columnas = features

double mean(const Vec& x) {
    double s = 0;
    for (double v : x) s += v;
    return s / x.size();
}

// ddof = 1 -> varianza muestral (divide entre n-1, insesgada)
double variance(const Vec& x, int ddof = 1) {
    double m = mean(x), s = 0;
    for (double v : x) s += (v - m) * (v - m);
    return s / (x.size() - ddof);
}

double covariance(const Vec& x, const Vec& y, int ddof = 1) {
    double mx = mean(x), my = mean(y), s = 0;
    for (size_t i = 0; i < x.size(); ++i) s += (x[i] - mx) * (y[i] - my);
    return s / (x.size() - ddof);
}

double pearson(const Vec& x, const Vec& y) {
    return covariance(x, y) / std::sqrt(variance(x) * variance(y));
}

// Matriz de covarianza d x d:  C = (1/(n-1)) * Xcᵀ Xc
Mat covMatrix(const Mat& X) {
    size_t n = X.size(), d = X[0].size();
    Vec mu(d, 0.0);
    for (auto& r : X) for (size_t j = 0; j < d; ++j) mu[j] += r[j] / n;
    Mat C(d, Vec(d, 0.0));
    for (auto& r : X)
        for (size_t a = 0; a < d; ++a)
            for (size_t b = 0; b < d; ++b)
                C[a][b] += (r[a] - mu[a]) * (r[b] - mu[b]) / (n - 1);
    return C;
}

// Estandarización z = (x - μ) / σ
Vec zscore(const Vec& x) {
    double m = mean(x), s = std::sqrt(variance(x));
    Vec z(x.size());
    for (size_t i = 0; i < x.size(); ++i) z[i] = (x[i] - m) / s;
    return z;
}

int main() {
    Vec horas = {1, 2, 3, 4, 5, 6};
    Vec nota  = {52, 55, 61, 64, 70, 74};
    std::printf("media=%.3f  var=%.3f  std=%.3f\n",
                mean(nota), variance(nota), std::sqrt(variance(nota)));
    std::printf("cov=%.3f  r=%.4f\n", covariance(horas, nota), pearson(horas, nota));
    Mat X;
    for (size_t i = 0; i < horas.size(); ++i) X.push_back({horas[i], nota[i]});
    Mat C = covMatrix(X);
    std::printf("C = [[%.2f, %.2f], [%.2f, %.2f]]\n", C[0][0], C[0][1], C[1][0], C[1][1]);
    Vec z = zscore(nota);
    std::printf("z[0]=%.3f  z[5]=%.3f\n", z[0], z[5]);
}

Sigmoide

Convierte cualquier número real en una probabilidad entre 0 y 1. Es la salida de la regresión logística y la activación clásica de las redes.

Para qué sirve

  • Salida de clasificadores binarios: P(y = 1 | x).
  • Compuertas en LSTM/GRU (deciden cuánto pasa, entre 0 y 1).
  • Activación histórica en capas ocultas (hoy casi siempre se usa ReLU).

Por qué funciona

La sigmoide es la inversa del logit: si el modelo predice log-odds z = log(p/(1−p)), despejar p da exactamente σ(z). Es monótona, simétrica alrededor de 0.5 y su derivada se calcula con su propio valor, lo que abarata el backprop. El problema: lejos del origen la pendiente se aplana (máximo 0.25), y en redes profundas esos gradientes pequeños se multiplican capa tras capa hasta desaparecer.

Fórmulas

Definición
σ(z) = 1 / (1 + e−z)
Derivada
σ′(z) = σ(z) (1 − σ(z))
Simetría
σ(−z) = 1 − σ(z)
Inversa (logit)
z = log(p / (1 − p))

Qué entra y qué sale

Entra
logit z ∈ ℝ
Sigmoide1 / (1 + e−z)
Sale
p ∈ (0, 1)

Flujo de cálculo

  1. Calcular el logit z = w·x + b.
  2. Si z ≥ 0 usar 1/(1+e−z); si no, ez/(1+ez) para evitar overflow.
  3. Interpretar el resultado como probabilidad de la clase positiva.
  4. Aplicar un umbral (0.5 por defecto) para decidir la clase.

Hiperparámetros

Sin hiperparámetros propios.

Costo: O(1) por elemento.

Cuidado con

  • Para multiclase excluyente usa softmax; la sigmoide por clase es para multi-etiqueta.
  • Entrena con BCEWithLogitsLoss, no con sigmoide + BCE por separado: es más estable.
  • Saturación: con |z| > 5 el gradiente es casi 0.

Implementación

// Sigmoide numéricamente estable y su derivada
#include <cmath>
#include <cstdio>

// σ(z) = 1 / (1 + e^{-z})
// Para z muy negativo, e^{-z} desborda: usamos la forma equivalente e^{z} / (1 + e^{z})
double sigmoid(double z) {
    if (z >= 0) {
        double e = std::exp(-z);
        return 1.0 / (1.0 + e);
    }
    double e = std::exp(z);
    return e / (1.0 + e);
}

// σ'(z) = σ(z) · (1 − σ(z))   → máximo 0.25 en z = 0
double sigmoidGrad(double z) {
    double s = sigmoid(z);
    return s * (1.0 - s);
}

// log σ(z) estable (útil en la pérdida logística): −log(1 + e^{−z})
double logSigmoid(double z) {
    return z >= 0 ? -std::log1p(std::exp(-z)) : z - std::log1p(std::exp(z));
}

int main() {
    double zs[] = {-800, -4, -1, 0, 1, 4, 800};
    for (double z : zs)
        std::printf("z=%7.1f  σ=%.6f  σ'=%.6f  logσ=%.4f\n",
                    z, sigmoid(z), sigmoidGrad(z), logSigmoid(z));
    // Ejemplo: logit de un modelo -> probabilidad de clase positiva
    double w[] = {0.8, -1.2}, b = 0.3, x[] = {2.0, 0.5};
    double logit = w[0] * x[0] + w[1] * x[1] + b;
    std::printf("logit=%.3f -> P(y=1|x)=%.4f\n", logit, sigmoid(logit));
}

Softmax

Generaliza la sigmoide a K clases: convierte un vector de scores en una distribución de probabilidad que suma 1.

Para qué sirve

  • Capa de salida de clasificadores multiclase (regresión logística multinomial, MLP, CNN).
  • Atención en Transformers: pesos sobre las posiciones.
  • Muestreo en modelos de lenguaje, controlado por la temperatura T.

Por qué funciona

La exponencial hace todo positivo y amplifica diferencias; dividir entre la suma normaliza. Sumar una constante a todos los logits no cambia el resultado, por eso se resta el máximo antes de exponenciar y así nunca hay overflow. La temperatura divide los logits: T < 1 concentra la masa en el mayor, T > 1 la reparte. Junto con la entropía cruzada su gradiente queda muy simple: p − one-hot(y).

Fórmulas

Softmax
softmax(z)i = ezi/T / Σj ezj/T
Estable
softmax(z) = softmax(z − max(z))
Log-sum-exp
log Σ ezj = m + log Σ ezj − m
Gradiente con CE
∂L/∂z = p − onehot(y)

Qué entra y qué sale

Entra
logits z ∈ ℝK
temperatura T
Softmaxexp(z − max) / Σ
Sale
p ∈ ΔK (suma 1)

Flujo de cálculo

  1. Recibir el vector de logits z (uno por clase).
  2. Dividir entre la temperatura T.
  3. Restar el máximo.
  4. Exponenciar cada componente.
  5. Dividir cada una entre la suma.
  6. Predicción = argmax; confianza = la probabilidad de esa clase.

Hiperparámetros

T
Temperatura. 1 = estándar; → 0 se vuelve argmax; grande → uniforme.

Costo: O(K).

Cuidado con

  • Las probabilidades de una red suelen estar mal calibradas (sobreconfiadas).
  • En PyTorch CrossEntropyLoss ya aplica log-softmax: pásale logits crudos.

Implementación

// Softmax estable (con temperatura), log-softmax y entropía cruzada
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <vector>
using Vec = std::vector<double>;

// softmax(z)_i = e^{z_i / T} / Σ_j e^{z_j / T}
// Restar max(z) no cambia el resultado y evita overflow.
Vec softmax(const Vec& z, double T = 1.0) {
    double m = *std::max_element(z.begin(), z.end());
    Vec p(z.size());
    double sum = 0;
    for (size_t i = 0; i < z.size(); ++i) sum += (p[i] = std::exp((z[i] - m) / T));
    for (double& v : p) v /= sum;
    return p;
}

// log-softmax = z_i − m − log Σ e^{z_j − m}  (log-sum-exp trick)
Vec logSoftmax(const Vec& z) {
    double m = *std::max_element(z.begin(), z.end()), s = 0;
    for (double v : z) s += std::exp(v - m);
    double lse = m + std::log(s);
    Vec out(z.size());
    for (size_t i = 0; i < z.size(); ++i) out[i] = z[i] - lse;
    return out;
}

// CE = −log p_y ; su gradiente respecto a z es (p − onehot(y))
double crossEntropy(const Vec& z, int y, Vec& grad) {
    Vec p = softmax(z);
    grad = p;
    grad[y] -= 1.0;
    return -logSoftmax(z)[y];
}

int main() {
    Vec logits = {2.0, 1.0, 0.1};
    for (double T : {0.5, 1.0, 2.0}) {
        Vec p = softmax(logits, T);
        std::printf("T=%.1f  p = [%.3f, %.3f, %.3f]\n", T, p[0], p[1], p[2]);
    }
    Vec g;
    double loss = crossEntropy(logits, 0, g);
    std::printf("CE(y=0)=%.4f  grad=[%.3f, %.3f, %.3f]\n", loss, g[0], g[1], g[2]);
    Vec big = {1000, 1001, 1002};  // sin el truco del max esto daría inf/inf
    Vec pb = softmax(big);
    std::printf("estable: [%.3f, %.3f, %.3f]\n", pb[0], pb[1], pb[2]);
}

Top-K

Quedarse con los K elementos de mayor score sin ordenar todo. Aparece en recomendación, búsqueda vectorial, métricas y generación de texto.

Para qué sirve

  • Recomendadores y búsqueda: devolver los K ítems más relevantes.
  • Top-K accuracy (ImageNet reporta top-1 y top-5).
  • Top-K sampling en LLMs: muestrear sólo entre los K tokens más probables.
  • KNN: los K vecinos más cercanos son un top-K sobre −distancia.

Por qué funciona

Ordenar cuesta O(n log n), pero sólo necesitamos K. Un min-heap de tamaño K guarda los mejores vistos hasta ahora; su raíz es el peor de ellos. Cada nuevo elemento se compara con la raíz: si es mayor la reemplaza, si no se descarta. Así cada elemento cuesta O(log K). Si no importa el orden interno, quickselect (nth_element, argpartition) lo hace en O(n) promedio.

Flujo de cálculo

  1. Crear un min-heap vacío.
  2. Recorrer los scores: mientras el heap tenga menos de K, insertar.
  3. Si el heap está lleno y el score supera la raíz, sacar la raíz e insertar el nuevo.
  4. Al final, extraer el heap y revertir para tener orden descendente.

Hiperparámetros

Cuántos elementos conservar.

Costo: Heap: O(n log K). Quickselect: O(n) promedio. Ordenar: O(n log n).

Cuidado con

  • Define cómo desempatar si hay scores iguales.
  • Para millones de vectores usa índices aproximados (FAISS, HNSW) en lugar de fuerza bruta.

Implementación

// Top-K: selección con min-heap O(n log k), top-k accuracy y top-k sampling
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <functional>
#include <queue>
#include <random>
#include <utility>
#include <vector>
using Vec = std::vector<double>;
using Pair = std::pair<double, int>;  // (score, índice)

// Mantiene un min-heap de tamaño k: la raíz es el "peor de los mejores".
std::vector<int> topK(const Vec& s, int k) {
    std::priority_queue<Pair, std::vector<Pair>, std::greater<Pair>> heap;
    for (int i = 0; i < (int)s.size(); ++i) {
        if ((int)heap.size() < k) heap.push({s[i], i});
        else if (s[i] > heap.top().first) { heap.pop(); heap.push({s[i], i}); }
    }
    std::vector<int> idx;
    while (!heap.empty()) { idx.push_back(heap.top().second); heap.pop(); }
    std::reverse(idx.begin(), idx.end());  // de mayor a menor
    return idx;
}

// Top-k accuracy: acierto si la clase verdadera está entre las k más probables
double topKAccuracy(const std::vector<Vec>& scores, const std::vector<int>& y, int k) {
    int hits = 0;
    for (size_t n = 0; n < scores.size(); ++n) {
        auto idx = topK(scores[n], k);
        hits += std::find(idx.begin(), idx.end(), y[n]) != idx.end();
    }
    return double(hits) / scores.size();
}

// Top-k sampling: renormaliza softmax sólo sobre los k mejores y muestrea
int topKSample(const Vec& logits, int k, std::mt19937& rng) {
    auto idx = topK(logits, k);
    Vec w;
    for (int i : idx) w.push_back(std::exp(logits[i] - logits[idx[0]]));
    std::discrete_distribution<int> d(w.begin(), w.end());
    return idx[d(rng)];
}

int main() {
    Vec s = {0.1, 2.5, -1.0, 3.7, 0.9, 2.2, 3.1};
    auto best = topK(s, 3);
    std::printf("top-3 índices: %d %d %d\n", best[0], best[1], best[2]);
    std::vector<Vec> P = {{0.1, 0.6, 0.3}, {0.5, 0.2, 0.3}, {0.2, 0.3, 0.5}};
    std::vector<int> y = {1, 2, 2};
    std::printf("top-1 acc=%.2f  top-2 acc=%.2f\n", topKAccuracy(P, y, 1), topKAccuracy(P, y, 2));
    std::mt19937 rng(7);
    std::printf("muestra top-3: %d\n", topKSample(s, 3, rng));
}

Funciones de pérdida

La función que el entrenamiento minimiza. Elegirla bien define qué errores castiga más el modelo.

Para qué sirve

  • MSE: regresión cuando los errores grandes deben pesar mucho.
  • MAE / Huber: regresión robusta a outliers.
  • Entropía cruzada binaria: clasificación binaria o multi-etiqueta.
  • Entropía cruzada categórica: clasificación multiclase.

Por qué funciona

MSE eleva el error al cuadrado: un error de 10 pesa 100 veces más que uno de 1, y su mínimo es la media condicional. MAE pesa todos los errores igual y su mínimo es la mediana. Huber es cuadrática cerca de cero y lineal lejos: combina lo mejor de ambas. La entropía cruzada mide cuánta probabilidad le diste a la respuesta correcta; −log p explota cuando p → 0, así que el modelo paga caro estar seguro y equivocado. Minimizarla equivale a máxima verosimilitud.

Fórmulas

MSE
L = (1/N) Σ (yi − ŷi)²
MAE
L = (1/N) Σ |yi − ŷi|
Huber
½r² si |r| ≤ δ; δ(|r| − ½δ) si no
BCE
L = −[y log p + (1 − y) log(1 − p)]
CCE
L = −Σk yk log pk = −log py

Entra
y real
ŷ o p predicho

Flujo de cálculo

  1. Obtener la predicción del modelo (valor o probabilidades).
  2. Calcular el error por muestra según la pérdida elegida.
  3. Recortar probabilidades a [ε, 1−ε] antes del log.
  4. Promediar sobre el batch.
  5. Derivar respecto a la predicción para iniciar el backprop.

Hiperparámetros

δ (Huber)
Dónde cambia de cuadrática a lineal.

Costo: O(N) por evaluación.

Cuidado con

  • MSE con sigmoide para clasificar da gradientes pobres; usa entropía cruzada.
  • La métrica que reportas (accuracy, F1) no tiene por qué ser la pérdida que optimizas.

// Funciones de pérdida: MSE, MAE, Huber, entropía cruzada binaria y categórica
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <vector>
using Vec = std::vector<double>;
const double EPS = 1e-12;

double mse(const Vec& y, const Vec& yh) {
    double s = 0;
    for (size_t i = 0; i < y.size(); ++i) s += (y[i] - yh[i]) * (y[i] - yh[i]);
    return s / y.size();
}

double mae(const Vec& y, const Vec& yh) {
    double s = 0;
    for (size_t i = 0; i < y.size(); ++i) s += std::fabs(y[i] - yh[i]);
    return s / y.size();
}

// Huber: cuadrática cerca de 0, lineal lejos -> robusta a outliers
double huber(const Vec& y, const Vec& yh, double delta = 1.0) {
    double s = 0;
    for (size_t i = 0; i < y.size(); ++i) {
        double r = std::fabs(y[i] - yh[i]);
        s += r <= delta ? 0.5 * r * r : delta * (r - 0.5 * delta);
    }
    return s / y.size();
}

// BCE = −[y log p + (1−y) log(1−p)]
double bce(const Vec& y, const Vec& p) {
    double s = 0;
    for (size_t i = 0; i < y.size(); ++i) {
        double q = std::clamp(p[i], EPS, 1 - EPS);
        s += -(y[i] * std::log(q) + (1 - y[i]) * std::log(1 - q));
    }
    return s / y.size();
}

// CCE con etiquetas enteras: −(1/N) Σ log p[n][y_n]
double cce(const std::vector<Vec>& P, const std::vector<int>& y) {
    double s = 0;
    for (size_t n = 0; n < P.size(); ++n) s += -std::log(std::max(P[n][y[n]], EPS));
    return s / P.size();
}

int main() {
    Vec y = {3.0, 5.0, 2.5, 7.0}, yh = {2.5, 5.0, 4.0, 8.0};
    std::printf("MSE=%.4f  MAE=%.4f  Huber=%.4f\n", mse(y, yh), mae(y, yh), huber(y, yh));
    Vec yb = {1, 0, 1, 1}, p = {0.9, 0.2, 0.6, 0.99};
    std::printf("BCE=%.4f\n", bce(yb, p));
    std::vector<Vec> P = {{0.7, 0.2, 0.1}, {0.1, 0.1, 0.8}};
    std::printf("CCE=%.4f\n", cce(P, {0, 2}));
}

Optimización y regularización

Descenso de gradiente, Momentum y Adam

El motor del aprendizaje: dar pasos en la dirección contraria al gradiente hasta llegar a un mínimo de la pérdida.

Para qué sirve

  • Entrenar regresión lineal/logística cuando la forma cerrada es cara.
  • Entrenar todas las redes neuronales (SGD, Adam, AdamW).
  • Cualquier problema de optimización diferenciable.

Por qué funciona

El gradiente apunta hacia donde la función crece más rápido; restarlo baja. Con la tasa de aprendizaje η demasiado grande se diverge, demasiado pequeña tarda una eternidad. En valles alargados el GD simple zigzaguea. Momentum acumula una velocidad que promedia las direcciones y cancela el zigzag. Adam además divide cada coordenada entre la raíz de su gradiente cuadrático promedio, así cada parámetro tiene su propio tamaño de paso. SGD usa un mini-batch en vez de todos los datos: el ruido resultante es barato y ayuda a escapar de mínimos malos.

Fórmulas

GD
w ← w − η ∇L(w)
Momentum
v ← βv + ∇L; w ← w − ηv
Adam (momentos)
m ← β₁m + (1−β₁)g; v ← β₂v + (1−β₂)g²
Adam (paso)
w ← w − η m̂ / (√v̂ + ε), m̂ = m/(1−β₁t)

Qué entra y qué sale

Entra
pérdida L(w)
∇L
η, β
Descenso de gradiente, Momentum y Adampaso contra el gradiente, iterado

Flujo de cálculo

  1. Inicializar parámetros (aleatorio pequeño o ceros según el modelo).
  2. Tomar un mini-batch y calcular la pérdida.
  3. Calcular el gradiente (analítico o autograd).
  4. Actualizar con la regla del optimizador.
  5. Repetir hasta que la pérdida de validación deje de mejorar.

Hiperparámetros

η
Tasa de aprendizaje; el hiperparámetro más importante.
β / β₁, β₂
Inercia: 0.9 y 0.999 por defecto en Adam.
batch size
Más grande = gradiente menos ruidoso pero menos actualizaciones por época.

Costo: O(costo del gradiente) por paso.

Cuidado con

  • Escala las features: un valle muy alargado hace lento al GD.
  • Usa un scheduler (warmup, cosine decay) en entrenamientos largos.
  • AdamW separa el weight decay del gradiente; es el estándar actual.

// Descenso de gradiente: vanilla, momentum y Adam sobre la función de Rosenbrock
#include <cmath>
#include <cstdio>
#include <functional>
#include <vector>
using Vec = std::vector<double>;

// f(x,y) = (1−x)² + 100(y−x²)²   mínimo global en (1,1)
double f(const Vec& w) {
    return (1 - w[0]) * (1 - w[0]) + 100 * (w[1] - w[0] * w[0]) * (w[1] - w[0] * w[0]);
}
Vec grad(const Vec& w) {
    return {-2 * (1 - w[0]) - 400 * w[0] * (w[1] - w[0] * w[0]),
            200 * (w[1] - w[0] * w[0])};
}

Vec vanilla(Vec w, double lr, int steps) {
    for (int t = 0; t < steps; ++t) {
        Vec g = grad(w);
        for (int i = 0; i < 2; ++i) w[i] -= lr * g[i];          // w ← w − η∇f
    }
    return w;
}

Vec momentum(Vec w, double lr, double beta, int steps) {
    Vec v(2, 0.0);
    for (int t = 0; t < steps; ++t) {
        Vec g = grad(w);
        for (int i = 0; i < 2; ++i) {
            v[i] = beta * v[i] + g[i];                            // velocidad acumulada
            w[i] -= lr * v[i];
        }
    }
    return w;
}

Vec adam(Vec w, double lr, int steps, double b1 = 0.9, double b2 = 0.999, double eps = 1e-8) {
    Vec m(2, 0.0), v(2, 0.0);
    for (int t = 1; t <= steps; ++t) {
        Vec g = grad(w);
        for (int i = 0; i < 2; ++i) {
            m[i] = b1 * m[i] + (1 - b1) * g[i];                   // 1er momento
            v[i] = b2 * v[i] + (1 - b2) * g[i] * g[i];            // 2º momento
            double mh = m[i] / (1 - std::pow(b1, t));             // corrección de sesgo
            double vh = v[i] / (1 - std::pow(b2, t));
            w[i] -= lr * mh / (std::sqrt(vh) + eps);
        }
    }
    return w;
}

int main() {
    Vec w0 = {-1.5, 2.0};
    Vec a = vanilla(w0, 1e-3, 20000), b = momentum(w0, 1e-4, 0.9, 20000), c = adam(w0, 0.02, 5000);
    std::printf("vanilla : (%.4f, %.4f) f=%.2e\n", a[0], a[1], f(a));
    std::printf("momentum: (%.4f, %.4f) f=%.2e\n", b[0], b[1], f(b));
    std::printf("adam    : (%.4f, %.4f) f=%.2e\n", c[0], c[1], f(c));
}

Regularización L1 y L2 (Lasso y Ridge)

Penalizar pesos grandes para que el modelo generalice. L2 encoge todos los pesos; L1 lleva varios exactamente a cero.

Para qué sirve

  • Combatir el sobreajuste cuando hay muchas features o pocas muestras.
  • Selección automática de features con Lasso (L1).
  • Estabilizar soluciones con features colineales (Ridge).
  • Weight decay en redes neuronales es L2.

Por qué funciona

Minimizar pérdida + λ·penalización equivale a minimizar la pérdida dentro de una región: una bola para L2, un rombo para L1. Las curvas de nivel de la pérdida son elipses que crecen desde el óptimo sin restricción hasta tocar la región. El rombo tiene esquinas sobre los ejes y las elipses casi siempre tocan primero una esquina, donde una coordenada vale 0. Por eso Lasso produce modelos dispersos y Ridge no. Desde la estadística, L2 es un prior gaussiano sobre los pesos y L1 un prior de Laplace.

Fórmulas

Ridge
min ‖y − Xw‖² + λ‖w‖₂² ⇒ w = (X⊤X + λI)−1X⊤y
Lasso
min (1/2N)‖y − Xw‖² + λ‖w‖₁
Soft-threshold
S(ρ, λ) = sign(ρ) · max(|ρ| − λ, 0)
Elastic Net
λ[α‖w‖₁ + (1−α)‖w‖₂²/2]

Qué entra y qué sale

Entra
X, y
λ
Regularización L1 y L2pérdida + λ·‖w‖
Sale
w encogido (L2) o disperso (L1)

Flujo de cálculo

  1. Estandarizar las features (la penalización depende de la escala).
  2. Elegir λ (y α en Elastic Net) por validación cruzada.
  3. Ridge: resolver el sistema lineal con λ sumado a la diagonal.
  4. Lasso: descenso por coordenadas; cada peso se actualiza con soft-threshold.
  5. Revisar qué coeficientes quedaron en cero.

Hiperparámetros

λ / alpha
Fuerza de la penalización. 0 = sin regularizar.
l1_ratio
Mezcla L1/L2 en Elastic Net.

Costo: Ridge: O(nd² + d³). Lasso: O(n·d) por pasada de coordenadas.

Cuidado con

  • No penalices el sesgo (intercepto).
  • Con features muy correlacionadas Lasso elige una al azar; Elastic Net las agrupa.
  • En sklearn C de LogisticRegression/SVC es 1/λ: más grande = menos regularización.

// Regularización: Ridge (L2, forma cerrada) y Lasso (L1, descenso por coordenadas)
#include <cmath>
#include <cstdio>
#include <random>
#include <vector>
using Vec = std::vector<double>;
using Mat = std::vector<Vec>;

Vec solve(Mat A, Vec b) {  // Gauss-Jordan
    int n = A.size();
    for (int c = 0; c < n; ++c) {
        int p = c;
        for (int r = c + 1; r < n; ++r) if (std::fabs(A[r][c]) > std::fabs(A[p][c])) p = r;
        std::swap(A[c], A[p]); std::swap(b[c], b[p]);
        for (int r = 0; r < n; ++r) if (r != c) {
            double f = A[r][c] / A[c][c];
            for (int k = c; k < n; ++k) A[r][k] -= f * A[c][k];
            b[r] -= f * b[c];
        }
    }
    for (int i = 0; i < n; ++i) b[i] /= A[i][i];
    return b;
}

// Ridge: w = (XᵀX + λI)⁻¹ Xᵀy   (X centrado, sin columna de sesgo)
Vec ridge(const Mat& X, const Vec& y, double lambda) {
    size_t d = X[0].size();
    Mat A(d, Vec(d, 0)); Vec b(d, 0);
    for (size_t n = 0; n < X.size(); ++n)
        for (size_t i = 0; i < d; ++i) {
            b[i] += X[n][i] * y[n];
            for (size_t j = 0; j < d; ++j) A[i][j] += X[n][i] * X[n][j];
        }
    for (size_t i = 0; i < d; ++i) A[i][i] += lambda;
    return solve(A, b);
}

double softThreshold(double rho, double lam) {  // S(ρ, λ)
    if (rho > lam) return rho - lam;
    if (rho < -lam) return rho + lam;
    return 0.0;                                  // ← aquí nacen los ceros de Lasso
}

// Lasso: min (1/2N)||y − Xw||² + λ||w||₁
Vec lasso(const Mat& X, const Vec& y, double lambda, int iters = 200) {
    size_t N = X.size(), d = X[0].size();
    Vec w(d, 0.0), r = y;                        // r = residuo y − Xw
    for (int it = 0; it < iters; ++it)
        for (size_t j = 0; j < d; ++j) {
            double rho = 0, z = 0;
            for (size_t n = 0; n < N; ++n) {
                rho += X[n][j] * (r[n] + X[n][j] * w[j]);
                z += X[n][j] * X[n][j];
            }
            double wj = softThreshold(rho / N, lambda) / (z / N);
            for (size_t n = 0; n < N; ++n) r[n] -= X[n][j] * (wj - w[j]);
            w[j] = wj;
        }
    return w;
}

Modelos lineales

Regresión lineal

Ajustar un hiperplano que minimiza el error cuadrático. El modelo más simple y el punto de partida de casi todo.

Para qué sirve

  • Predecir un valor continuo (precio, demanda, tiempo).
  • Interpretar el efecto de cada variable (coeficientes).
  • Línea base obligatoria antes de modelos más complejos.

Por qué funciona

La predicción es una suma ponderada de las features. Minimizar el MSE da una función cuadrática convexa de los pesos, con un único mínimo. Igualar el gradiente a cero da la ecuación normal, que se resuelve en un paso. Geométricamente, Xθ es la proyección ortogonal de y sobre el espacio columna de X: el residuo queda perpendicular a todas las features. Cuando d es grande o los datos no caben en memoria se usa descenso de gradiente.

Fórmulas

Modelo
ŷ = θ⊤x = θ₀ + θ₁x₁ + … + θdxd
Ecuación normal
θ = (X⊤X)−1X⊤y
Gradiente
∇MSE = (2/N) X⊤(Xθ − y)
R²
R² = 1 − Σ(y − ŷ)² / Σ(y − ȳ)²

Qué entra y qué sale

Entra
X (n × d)
y (n)
Regresión linealmínimos cuadrados
Sale
θ (d+1)
ŷ = Xθ

Flujo de cálculo

  1. Añadir una columna de unos a X para el sesgo.
  2. Opción A: formar X⊤X y X⊤y y resolver el sistema.
  3. Opción B: iniciar θ = 0 y repetir θ ← θ − η∇MSE.
  4. Evaluar con R², RMSE o MAE en datos no vistos.
  5. Revisar residuos: deben verse como ruido sin patrón.

Hiperparámetros

fit_intercept
Si se aprende θ₀.
η, épocas
Sólo en la versión por gradiente.

Costo: Ecuación normal O(nd² + d³). GD O(nd) por época.

Cuidado con

  • Supuestos: relación lineal, residuos independientes y de varianza constante.
  • Colinealidad infla la varianza de los coeficientes; usa Ridge.
  • Para relaciones no lineales, añade features polinómicas o usa otro modelo.

// Regresión lineal: ecuación normal (Gauss-Jordan) y descenso de gradiente
#include <cmath>
#include <cstdio>
#include <random>
#include <vector>
using Vec = std::vector<double>;
using Mat = std::vector<Vec>;

// Resuelve A x = b por eliminación de Gauss-Jordan con pivoteo parcial
Vec solve(Mat A, Vec b) {
    int n = A.size();
    for (int c = 0; c < n; ++c) {
        int p = c;
        for (int r = c + 1; r < n; ++r) if (std::fabs(A[r][c]) > std::fabs(A[p][c])) p = r;
        std::swap(A[c], A[p]); std::swap(b[c], b[p]);
        for (int r = 0; r < n; ++r) if (r != c) {
            double f = A[r][c] / A[c][c];
            for (int k = c; k < n; ++k) A[r][k] -= f * A[c][k];
            b[r] -= f * b[c];
        }
    }
    for (int i = 0; i < n; ++i) b[i] /= A[i][i];
    return b;
}

// θ = (XᵀX)⁻¹ Xᵀy   (X incluye una columna de 1s para el sesgo)
Vec normalEquation(const Mat& X, const Vec& y) {
    size_t d = X[0].size();
    Mat XtX(d, Vec(d, 0)); Vec Xty(d, 0);
    for (size_t n = 0; n < X.size(); ++n)
        for (size_t i = 0; i < d; ++i) {
            Xty[i] += X[n][i] * y[n];
            for (size_t j = 0; j < d; ++j) XtX[i][j] += X[n][i] * X[n][j];
        }
    return solve(XtX, Xty);
}

// ∇MSE = (2/N) Xᵀ(Xθ − y)
Vec gradientDescent(const Mat& X, const Vec& y, double lr, int epochs) {
    size_t N = X.size(), d = X[0].size();
    Vec th(d, 0.0);
    for (int e = 0; e < epochs; ++e) {
        Vec g(d, 0.0);
        for (size_t n = 0; n < N; ++n) {
            double r = -y[n];
            for (size_t j = 0; j < d; ++j) r += X[n][j] * th[j];
            for (size_t j = 0; j < d; ++j) g[j] += 2.0 * r * X[n][j] / N;
        }
        for (size_t j = 0; j < d; ++j) th[j] -= lr * g[j];
    }
    return th;
}

double r2(const Mat& X, const Vec& y, const Vec& th) {
    double my = 0, ssr = 0, sst = 0;
    for (double v : y) my += v / y.size();
    for (size_t n = 0; n < X.size(); ++n) {
        double p = 0;
        for (size_t j = 0; j < th.size(); ++j) p += X[n][j] * th[j];
        ssr += (y[n] - p) * (y[n] - p);
        sst += (y[n] - my) * (y[n] - my);
    }
    return 1 - ssr / sst;
}

Regresión logística

Un modelo lineal que predice probabilidades pasando el logit por una sigmoide. Clasificador base por excelencia.

Para qué sirve

  • Clasificación binaria con probabilidades interpretables (riesgo, churn, fraude).
  • Multiclase con softmax (regresión multinomial).
  • Base para scorecards: cada coeficiente es un cambio en log-odds.

Por qué funciona

Modela el log-odds como función lineal de las features. La frontera de decisión w·x + b = 0 es un hiperplano. No hay forma cerrada, pero la pérdida (BCE) es convexa, así que el descenso de gradiente llega al óptimo global. El gradiente tiene la misma forma que en regresión lineal: error × feature, con el error ahora en escala de probabilidad. En la animación el fondo es P(azul | x) y se ve cómo la frontera rota y se afila.

Fórmulas

Modelo
P(y=1 | x) = σ(w⊤x + b)
Log-odds
log(p/(1−p)) = w⊤x + b
Pérdida
L = −(1/N) Σ [y log p + (1−y) log(1−p)] + (λ/2)‖w‖²
Gradiente
∇wL = (1/N) X⊤(p − y) + λw

Qué entra y qué sale

Entra
X (n × d)
y ∈ {0,1}
Regresión logísticaσ(w·x+b) + BCE + GD
Sale
w, b
P(y=1|x)

Flujo de cálculo

  1. Escalar features e iniciar w = 0.
  2. Calcular z = Xw + b y p = σ(z).
  3. Calcular el gradiente (p − y) ponderado por X.
  4. Actualizar w y b.
  5. Repetir hasta converger; elegir el umbral según el costo de errores.

Hiperparámetros

C = 1/λ
Inverso de la regularización.
penalty
l2, l1 o elasticnet.
umbral
0.5 por defecto; muévelo según precision/recall.

Costo: O(nd) por época.

Cuidado con

  • Datos perfectamente separables: sin regularización los pesos crecen sin límite.
  • Clases desbalanceadas: usa class_weight='balanced' o ajusta el umbral.

// Regresión logística binaria con descenso de gradiente (batch) y L2
#include <cmath>
#include <cstdio>
#include <random>
#include <vector>
using Vec = std::vector<double>;
using Mat = std::vector<Vec>;

double sigmoid(double z) { return z >= 0 ? 1 / (1 + std::exp(-z)) : std::exp(z) / (1 + std::exp(z)); }

struct LogisticRegression {
    Vec w; double b = 0;

    double predictProba(const Vec& x) const {
        double z = b;
        for (size_t j = 0; j < w.size(); ++j) z += w[j] * x[j];
        return sigmoid(z);
    }

    // Pérdida: BCE + (λ/2)||w||².  Gradiente: (1/N) Xᵀ(p − y) + λw
    void fit(const Mat& X, const Vec& y, double lr = 0.1, int epochs = 2000, double lambda = 1e-3) {
        size_t N = X.size(), d = X[0].size();
        w.assign(d, 0.0); b = 0;
        for (int e = 0; e < epochs; ++e) {
            Vec gw(d, 0.0); double gb = 0, loss = 0;
            for (size_t n = 0; n < N; ++n) {
                double p = predictProba(X[n]), err = p - y[n];
                for (size_t j = 0; j < d; ++j) gw[j] += err * X[n][j] / N;
                gb += err / N;
                loss += -(y[n] * std::log(p + 1e-12) + (1 - y[n]) * std::log(1 - p + 1e-12)) / N;
            }
            for (size_t j = 0; j < d; ++j) w[j] -= lr * (gw[j] + lambda * w[j]);
            b -= lr * gb;
            if (e % 500 == 0) std::printf("epoch %4d  loss=%.4f\n", e, loss);
        }
    }
    int predict(const Vec& x, double thr = 0.5) const { return predictProba(x) >= thr; }
};

int main() {
    std::mt19937 rng(3);
    std::normal_distribution<double> G(0, 1);
    Mat X; Vec y;
    for (int i = 0; i < 200; ++i) {   // dos nubes gaussianas
        int c = i % 2;
        X.push_back({G(rng) + (c ? 2.0 : -2.0), G(rng) + (c ? 1.0 : -1.0)});
        y.push_back(c);
    }
    LogisticRegression m;
    m.fit(X, y);
    int ok = 0;
    for (size_t n = 0; n < X.size(); ++n) ok += m.predict(X[n]) == y[n];
    std::printf("w=(%.3f, %.3f) b=%.3f  accuracy=%.3f\n", m.w[0], m.w[1], m.b, ok / 200.0);
    // Frontera de decisión: w·x + b = 0  ⇔  P = 0.5
}

Perceptrón

La neurona artificial original (1958): una suma ponderada con escalón que corrige sus pesos sólo cuando se equivoca.

Para qué sirve

  • Entender la base de las redes neuronales.
  • Clasificación lineal online muy barata.
  • Mostrar por qué hacen falta capas ocultas (el problema XOR).

Por qué funciona

Si un punto positivo cae del lado negativo, sumar x a w gira el hiperplano hacia él; si un negativo cae del lado positivo, restarlo lo aleja. El teorema de convergencia garantiza que, si existe un hiperplano que separa las clases con margen γ, el perceptrón lo encuentra en a lo más (R/γ)² errores. Si no son separables, como XOR, nunca converge: esa limitación detuvo la investigación en redes hasta el backprop.

Fórmulas

Predicción
ŷ = sign(w⊤x + b)
Actualización
si ŷ ≠ y: w ← w + η y x, b ← b + η y
Cota de errores
errores ≤ (R / γ)²

Qué entra y qué sale

Entra
x (d)
y ∈ {−1, +1}
Perceptrónescalón(w·x+b)
Sale
w, b
clase ±1

Flujo de cálculo

  1. Iniciar w = 0, b = 0; etiquetas en {−1, +1}.
  2. Recorrer los puntos uno por uno.
  3. Si el punto está bien clasificado, no hacer nada.
  4. Si está mal, sumar η·y·x a los pesos.
  5. Terminar cuando una época completa no tenga errores.

Hiperparámetros

η
Tasa de aprendizaje (con w=0 inicial, su escala no cambia las predicciones).

Costo: O(d) por actualización.

Cuidado con

  • No da probabilidades ni margen máximo.
  • Sólo funciona si los datos son linealmente separables.

// Perceptrón de Rosenblatt: la neurona original, regla de actualización sólo en errores
#include <cstdio>
#include <vector>
using Vec = std::vector<double>;

struct Perceptron {
    Vec w; double b = 0;

    int predict(const Vec& x) const {               // escalón: sign(w·x + b)
        double z = b;
        for (size_t j = 0; j < w.size(); ++j) z += w[j] * x[j];
        return z >= 0 ? 1 : -1;
    }

    // Converge en un número finito de pasos SI los datos son linealmente separables
    int fit(const std::vector<Vec>& X, const std::vector<int>& y, double lr = 1.0, int maxEpochs = 100) {
        w.assign(X[0].size(), 0.0);
        for (int e = 0; e < maxEpochs; ++e) {
            int errors = 0;
            for (size_t i = 0; i < X.size(); ++i)
                if (predict(X[i]) != y[i]) {           // w ← w + η·y·x
                    for (size_t j = 0; j < w.size(); ++j) w[j] += lr * y[i] * X[i][j];
                    b += lr * y[i];
                    ++errors;
                }
            std::printf("época %d  errores=%d\n", e, errors);
            if (errors == 0) return e;
        }
        return -1;
    }
};

int main() {
    // Compuerta AND con etiquetas {−1, +1}: separable
    std::vector<Vec> X = {{0, 0}, {0, 1}, {1, 0}, {1, 1}};
    std::vector<int> AND = {-1, -1, -1, 1}, XOR = {-1, 1, 1, -1};
    Perceptron p;
    p.fit(X, AND);
    std::printf("AND: w=(%.1f, %.1f) b=%.1f\n", p.w[0], p.w[1], p.b);
    Perceptron q;
    int r = q.fit(X, XOR, 1.0, 5);                   // XOR no es separable: nunca converge
    std::printf("XOR convergió? %s  → hace falta una capa oculta (MLP)\n", r < 0 ? "no" : "sí");
}

Máquinas de soporte vectorial (SVM)

El hiperplano que separa las clases con el mayor margen posible. Con kernels, fronteras no lineales sin calcular las features.

Para qué sirve

  • Clasificación con pocas muestras y muchas features (texto, genómica).
  • Fronteras no lineales con kernel RBF o polinómico.
  • Regresión (SVR) y detección de anomalías (One-Class SVM).

Por qué funciona

Entre todos los hiperplanos que separan, el de margen máximo es el más robusto a ruido nuevo. El margen vale 2/‖w‖, así que maximizarlo es minimizar ‖w‖². La hinge loss permite violaciones con un costo. Sólo los puntos sobre o dentro del margen (vectores de soporte) definen la solución: puedes borrar el resto y el modelo no cambia. El truco del kernel reemplaza productos punto por K(x, x′), que equivale a trabajar en un espacio de mayor dimensión sin construirlo.

Fórmulas

Primal (soft margin)
min (λ/2)‖w‖² + (1/N) Σ max(0, 1 − yi(w·xi + b))
Margen
ancho = 2 / ‖w‖
Pegasos
ηt = 1/(λt); w ← (1−ηtλ)w + ηtyixi si viola
Kernel RBF
K(x, x′) = exp(−γ‖x − x′‖²)

Qué entra y qué sale

Entra
X escalado
y ∈ {−1, +1}
C, kernel
Máquinas de soporte vectorialmaximizar margen + hinge
Sale
w, b o α (dual)
vectores de soporte
signo de f(x)

Flujo de cálculo

  1. Escalar las features (obligatorio).
  2. Elegir kernel: lineal si hay muchas features, RBF si no.
  3. Optimizar el primal (Pegasos/SGD) o el dual (SMO, lo que hace libsvm).
  4. Identificar los vectores de soporte.
  5. Buscar C y γ con validación cruzada.

Hiperparámetros

C
Costo por violar el margen; grande = margen estrecho, riesgo de sobreajuste.
γ (RBF)
Alcance de cada punto; grande = fronteras muy curvas.
kernel
linear, rbf, poly, sigmoid.

Costo: Lineal: O(nd) por época. Kernel: entre O(n²) y O(n³).

Cuidado con

  • No escala bien más allá de ~100k muestras con kernel (O(n²) memoria).
  • No da probabilidades nativas; probability=True calibra aparte y es lento.

// SVM lineal con Pegasos (sub-gradiente estocástico de la hinge loss)
// min (λ/2)||w||² + (1/N) Σ max(0, 1 − y_i (w·x_i + b)),   y ∈ {−1, +1}
#include <cmath>
#include <cstdio>
#include <random>
#include <vector>
using Vec = std::vector<double>;

struct LinearSVM {
    Vec w; double b = 0;

    double decision(const Vec& x) const {
        double s = b;
        for (size_t j = 0; j < w.size(); ++j) s += w[j] * x[j];
        return s;
    }

    // Truco estándar: añadir una feature constante 1 → el sesgo b es el último peso
    void fit(const std::vector<Vec>& X, const Vec& y, double lambda = 0.05, int iters = 50000, unsigned seed = 0) {
        std::mt19937 rng(seed);
        std::uniform_int_distribution<size_t> pick(0, X.size() - 1);
        size_t d = X[0].size();
        Vec wa(d + 1, 0.0);                                  // [w, b]
        for (int t = 1; t <= iters; ++t) {
            size_t i = pick(rng);
            double eta = 1.0 / (lambda * t);                 // tasa decreciente
            double z = wa[d];
            for (size_t j = 0; j < d; ++j) z += wa[j] * X[i][j];
            bool violates = y[i] * z < 1;                    // dentro del margen o mal clasificado
            for (size_t j = 0; j <= d; ++j) {
                double xj = j < d ? X[i][j] : 1.0;
                wa[j] *= (1 - eta * lambda);                 // término de regularización
                if (violates) wa[j] += eta * y[i] * xj;      // término de la hinge
            }
        }
        w.assign(wa.begin(), wa.begin() + d);
        b = wa[d];
    }

    int predict(const Vec& x) const { return decision(x) >= 0 ? 1 : -1; }
    double margin() const { double n = 0; for (double v : w) n += v * v; return 2.0 / std::sqrt(n); }
};

int main() {
    std::mt19937 rng(5);
    std::normal_distribution<double> G(0, 0.6);
    std::vector<Vec> X; Vec y;
    for (int i = 0; i < 100; ++i) {
        double c = i % 2 ? 1 : -1;
        X.push_back({c * 1.5 + G(rng), c * 1.5 + G(rng)});
        y.push_back(c);
    }
    LinearSVM svm;
    svm.fit(X, y);
    int ok = 0, sv = 0;
    for (size_t i = 0; i < X.size(); ++i) {
        ok += svm.predict(X[i]) == y[i];
        sv += y[i] * svm.decision(X[i]) <= 1.0 + 1e-6;  // vectores de soporte (sobre/dentro del margen)
    }
    std::printf("w=(%.3f, %.3f) b=%.3f  margen=%.3f  acc=%.2f  SV≈%d\n",
                svm.w[0], svm.w[1], svm.b, svm.margin(), ok / 100.0, sv);
}

K vecinos más cercanos (KNN)

Clasificar un punto por votación de los K ejemplos más parecidos. No entrena nada: memoriza.

Para qué sirve

  • Línea base no paramétrica rápida de probar.
  • Recomendación por similitud e imputación de valores faltantes.
  • Búsqueda semántica sobre embeddings (con índices aproximados).

Por qué funciona

Supone que puntos cercanos comparten etiqueta. Con K = 1 la frontera sigue cada punto y sobreajusta; con K grande se suaviza y pierde detalle: K controla el balance sesgo-varianza. Todo depende de la distancia, así que una feature en miles domina sobre una en decimales si no se escala. En alta dimensión las distancias se parecen todas (maldición de la dimensionalidad) y KNN pierde poder.

Voto

Peso por distancia
wi = 1 / d(x, xi)
Regresión
ŷ = (1/K) Σi∈NK yi

Qué entra y qué sale

datos de entrenamiento

Sale
clase ŷ
proporción de votos

Flujo de cálculo

  1. Guardar los datos de entrenamiento (ya escalados).
  2. Para un punto nuevo, calcular la distancia a todos.
  3. Seleccionar los K más cercanos (top-K sobre −distancia).
  4. Votar la clase (o promediar si es regresión).
  5. Elegir K impar y por validación cruzada.

uniform o distance.
metric
euclidean, manhattan, cosine…

Costo: Entrenar O(1). Predecir O(n·d) fuerza bruta, ~O(log n) con KD-tree en baja dimensión.

Cuidado con

  • Predicción lenta: O(n·d) por consulta sin índice.
  • Escala las features siempre.

// k-Nearest Neighbors: clasificación por voto mayoritario (opcionalmente ponderado)
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <map>
#include <vector>
using Vec = std::vector<double>;

double euclid2(const Vec& a, const Vec& b) {
    double s = 0;
    for (size_t i = 0; i < a.size(); ++i) s += (a[i] - b[i]) * (a[i] - b[i]);
    return s;
}

struct KNN {
    int k; bool weighted;
    std::vector<Vec> X; std::vector<int> y;

    void fit(const std::vector<Vec>& X_, const std::vector<int>& y_) { X = X_; y = y_; }  // "lazy"

    int predict(const Vec& q) const {
        std::vector<std::pair<double, int>> d;               // (distancia², etiqueta)
        for (size_t i = 0; i < X.size(); ++i) d.push_back({euclid2(q, X[i]), y[i]});
        // nth_element: deja los k más cercanos al frente en O(n)
        std::nth_element(d.begin(), d.begin() + k, d.end());
        std::map<int, double> votes;
        for (int i = 0; i < k; ++i)
            votes[d[i].second] += weighted ? 1.0 / (std::sqrt(d[i].first) + 1e-9) : 1.0;
        return std::max_element(votes.begin(), votes.end(),
                                [](auto& a, auto& b) { return a.second < b.second; })->first;
    }
};

int main() {
    std::vector<Vec> X = {{1, 1}, {1.5, 2}, {2, 1.2}, {6, 6}, {6.5, 7}, {7, 6.2}, {3.5, 4}};
    std::vector<int> y = {0, 0, 0, 1, 1, 1, 1};
    KNN knn{3, true};
    knn.fit(X, y);
    for (Vec q : {Vec{1.2, 1.4}, Vec{5.5, 6}, Vec{3.2, 3.0}})
        std::printf("(%.1f, %.1f) -> clase %d\n", q[0], q[1], knn.predict(q));
}

Naive Bayes

Aplicar el teorema de Bayes suponiendo que las features son independientes dada la clase. Ingenuo, rápido y sorprendentemente bueno.

Para qué sirve

  • Clasificación de texto: spam, sentimiento, temas.
  • Línea base con muy pocos datos.
  • Modelos que deben entrenar en una pasada y actualizarse online.

Por qué funciona

Bayes dice que el posterior es proporcional a prior × verosimilitud. Estimar la verosimilitud conjunta de muchas features es imposible con pocos datos, pero si las suponemos independientes dada la clase se factoriza en un producto de distribuciones de una variable, cada una fácil de estimar. La suposición casi nunca es cierta, pero para elegir la clase sólo importa cuál posterior es mayor, y eso suele sobrevivir. En la animación, mover el prior desplaza el punto donde una clase pasa a ganar.

Fórmulas

Bayes
P(c | x) = P(x | c) P(c) / P(x)
Supuesto ingenuo
P(x | c) = Πj P(xj | c)
Gaussiano
P(xj | c) = 𝒩(xj; μcj, σ²cj)
Decisión (log)
ŷ = argmaxc [log P(c) + Σj log P(xj | c)]

Qué entra y qué sale

Entra
X, y
Naive Bayescontar / estimar μ, σ² por clase
Sale
priors
μ, σ² por clase y feature
P(c | x)

Flujo de cálculo

  1. Calcular el prior de cada clase: frecuencia relativa.
  2. Por clase y feature, estimar la distribución (media y varianza, o conteos con suavizado de Laplace).
  3. Para un punto nuevo, sumar log-prior y log-verosimilitudes por clase.
  4. Elegir la clase con mayor suma; normalizar con softmax si quieres probabilidades.

Hiperparámetros

var_smoothing
Gaussiano: varianza mínima añadida.
alpha
Multinomial/Bernoulli: suavizado de Laplace.

Costo: Entrenar O(nd). Predecir O(Kd).

Cuidado con

  • Las probabilidades salen extremas (cerca de 0 o 1): no las tomes como calibradas.
  • Features muy correlacionadas se cuentan dos veces.

// Naive Bayes Gaussiano: P(c|x) ∝ P(c) Π_j N(x_j | μ_cj, σ²_cj)
#include <cmath>
#include <cstdio>
#include <map>
#include <vector>
using Vec = std::vector<double>;

struct GaussianNB {
    std::map<int, double> logPrior;
    std::map<int, Vec> mu, var;

    void fit(const std::vector<Vec>& X, const std::vector<int>& y) {
        size_t d = X[0].size();
        std::map<int, int> cnt;
        for (size_t n = 0; n < X.size(); ++n) {
            int c = y[n]; cnt[c]++;
            if (!mu.count(c)) { mu[c] = Vec(d, 0); var[c] = Vec(d, 0); }
            for (size_t j = 0; j < d; ++j) mu[c][j] += X[n][j];
        }
        for (auto& [c, m] : mu) for (double& v : m) v /= cnt[c];
        for (size_t n = 0; n < X.size(); ++n)
            for (size_t j = 0; j < d; ++j) {
                double t = X[n][j] - mu[y[n]][j];
                var[y[n]][j] += t * t / cnt[y[n]];
            }
        for (auto& [c, v] : var) for (double& s : v) s += 1e-9;   // var_smoothing
        for (auto& [c, k] : cnt) logPrior[c] = std::log(double(k) / X.size());
    }

    // Trabajamos en log para no multiplicar probabilidades diminutas
    std::map<int, double> logPosterior(const Vec& x) const {
        std::map<int, double> out;
        for (auto& [c, lp] : logPrior) {
            double s = lp;
            for (size_t j = 0; j < x.size(); ++j) {
                double v = var.at(c)[j], d = x[j] - mu.at(c)[j];
                s += -0.5 * std::log(2 * M_PI * v) - d * d / (2 * v);
            }
            out[c] = s;
        }
        return out;
    }

    int predict(const Vec& x) const {
        auto lp = logPosterior(x);
        int best = lp.begin()->first;
        for (auto& [c, v] : lp) if (v > lp[best]) best = c;
        return best;
    }
};

Árboles y ensambles

Árbol de decisión

Partir el espacio con preguntas del tipo «¿xj ≤ t?» elegidas para que cada grupo quede lo más puro posible.

Para qué sirve

  • Modelos interpretables: las reglas se leen como un diagrama de flujo.
  • Datos tabulares con mezcla de tipos y sin escalar.
  • Bloque base de Random Forest y Gradient Boosting.

Por qué funciona

En cada nodo se prueban todas las features y todos los umbrales candidatos, y se elige el corte que más reduce la impureza. Gini mide la probabilidad de equivocarse si etiquetas al azar según las proporciones del nodo; la entropía mide la incertidumbre en bits. El algoritmo es voraz: elige el mejor corte local sin mirar adelante. Sin límites, el árbol crece hasta tener hojas puras y memoriza el ruido; profundidad máxima, mínimo de muestras por hoja o poda lo controlan. Las fronteras siempre son paralelas a los ejes.

Fórmulas

Gini
G = 1 − Σk pk²
Entropía
H = −Σk pk log₂ pk
Ganancia
Δ = I(padre) − (nL/n) I(L) − (nR/n) I(R)
Regresión
impureza = varianza del nodo; hoja = media

Qué entra y qué sale

Entra

Flujo de cálculo

  1. Empezar con todos los datos en la raíz.
  2. Para cada feature, ordenar valores y probar umbrales en los puntos medios.
  3. Elegir el par (feature, umbral) con mayor ganancia.
  4. Dividir en hijo izquierdo y derecho.
  5. Repetir recursivamente hasta llegar a un criterio de parada.
  6. Cada hoja predice la clase mayoritaria.

Hiperparámetros

Profundidad máxima.
min_samples_leaf
Mínimo de muestras por hoja.

gini o entropy.

Poda por costo-complejidad.

Costo: Entrenar O(d · n log n · profundidad). Predecir O(profundidad).

Cuidado con

  • Alta varianza: un cambio pequeño en los datos cambia todo el árbol.
  • La importancia por impureza favorece features con muchos valores distintos.

// Árbol de decisión CART (clasificación) con impureza de Gini
#include <algorithm>
#include <cstdio>
#include <map>
#include <memory>
#include <vector>
using Vec = std::vector<double>;

double gini(const std::vector<int>& y, const std::vector<int>& idx) {
    std::map<int, int> c;
    for (int i : idx) c[y[i]]++;
    double g = 1.0;
    for (auto& [k, v] : c) { double p = double(v) / idx.size(); g -= p * p; }
    return g;                                   // G = 1 − Σ p_k²
}

int majority(const std::vector<int>& y, const std::vector<int>& idx) {
    std::map<int, int> c;
    for (int i : idx) c[y[i]]++;
    return std::max_element(c.begin(), c.end(), [](auto& a, auto& b) { return a.second < b.second; })->first;
}

struct Node {
    int feature = -1; double thr = 0; int label = -1;
    std::unique_ptr<Node> left, right;
};

struct DecisionTree {
    int maxDepth, minSamples, maxFeatures;      // maxFeatures < d → aleatoriedad (Random Forest)
    std::unique_ptr<Node> root;
    std::vector<int> featPool;

    std::unique_ptr<Node> build(const std::vector<Vec>& X, const std::vector<int>& y,
                                std::vector<int> idx, int depth, unsigned& seed) {
        auto node = std::make_unique<Node>();
        double parentG = gini(y, idx);
        if (depth >= maxDepth || (int)idx.size() < minSamples || parentG == 0) {
            node->label = majority(y, idx);
            return node;
        }
        int d = X[0].size();
        std::vector<int> feats(d);
        for (int j = 0; j < d; ++j) feats[j] = j;
        for (int j = d - 1; j > 0; --j) { seed = seed * 1103515245 + 12345; std::swap(feats[j], feats[seed % (j + 1)]); }
        feats.resize(std::min(maxFeatures, d));

        double bestGain = 0; int bf = -1; double bt = 0;
        for (int f : feats) {
            std::vector<double> vals;
            for (int i : idx) vals.push_back(X[i][f]);
            std::sort(vals.begin(), vals.end());
            for (size_t k = 1; k < vals.size(); ++k) {
                if (vals[k] == vals[k - 1]) continue;
                double t = 0.5 * (vals[k] + vals[k - 1]);   // umbral = punto medio
                std::vector<int> L, R;
                for (int i : idx) (X[i][f] <= t ? L : R).push_back(i);
                // Ganancia = G(padre) − Σ (n_hijo/n) G(hijo)
                double gain = parentG - (L.size() * gini(y, L) + R.size() * gini(y, R)) / idx.size();
                if (gain > bestGain) { bestGain = gain; bf = f; bt = t; }
            }
        }
        if (bf < 0) { node->label = majority(y, idx); return node; }
        std::vector<int> L, R;
        for (int i : idx) (X[i][bf] <= bt ? L : R).push_back(i);
        node->feature = bf; node->thr = bt;
        node->left = build(X, y, L, depth + 1, seed);
        node->right = build(X, y, R, depth + 1, seed);
        return node;
    }

    void fit(const std::vector<Vec>& X, const std::vector<int>& y, std::vector<int> idx = {}, unsigned seed = 42) {
        if (idx.empty()) for (size_t i = 0; i < X.size(); ++i) idx.push_back(i);
        root = build(X, y, idx, 0, seed);
    }

    int predict(const Vec& x) const {
        const Node* n = root.get();
        while (n->label < 0) n = x[n->feature] <= n->thr ? n->left.get() : n->right.get();
        return n->label;
    }
};

Random Forest

Muchos árboles distintos entrenados con datos y features al azar, que votan. Reduce la varianza de un árbol sin aumentar el sesgo.

Para qué sirve

  • Primer modelo serio para casi cualquier problema tabular.
  • Estimar importancia de features.
  • Validación gratuita con el error out-of-bag.

Por qué funciona

Promediar B modelos con varianza σ² y correlación ρ deja una varianza ρσ² + (1−ρ)σ²/B. Más árboles bajan el segundo término; para bajar el primero hay que decorrelacionarlos. Bagging lo hace dando a cada árbol una muestra bootstrap (con reemplazo), y Random Forest además restringe cada corte a un subconjunto aleatorio de features (√d en clasificación). En la animación, el recuadro muestra un árbol suelto con sus fronteras dentadas; el fondo grande es el voto de todos, cada vez más suave.

Fórmulas

Voto
ŷ(x) = moda{ Tb(x) }b=1..B
Varianza del promedio
Var = ρσ² + (1 − ρ)σ² / B
Fuera de bolsa
P(muestra no elegida) = (1 − 1/n)n ≈ 0.368

Qué entra y qué sale

Entra
X, y
B, m
Random Forestbootstrap + features al azar + voto
Sale
B árboles
clase y proporción de votos
OOB score

Flujo de cálculo

  1. Para b = 1..B: tomar n muestras con reemplazo.
  2. Entrenar un árbol profundo; en cada nodo considerar sólo m features al azar.
  3. No podar: la varianza la elimina el promedio.
  4. Predecir por voto mayoritario (o promedio en regresión).
  5. Evaluar cada muestra con los árboles que no la vieron (OOB).

Hiperparámetros

n_estimators
Número de árboles; más nunca sobreajusta, sólo cuesta tiempo.
max_features
Features por corte: sqrt, log2, fracción.
max_depth / min_samples_leaf
Tamaño de cada árbol.

Costo: O(B · d′ · n log n · profundidad); paralelizable por árbol.

Cuidado con

  • Pierde la interpretabilidad de un solo árbol.
  • No extrapola fuera del rango visto en entrenamiento.

// Random Forest = bagging (bootstrap) + subconjunto aleatorio de features + voto
// Reutiliza DecisionTree de la sección "Árbol de decisión".
#define TREE_NO_MAIN
#include "tree.cpp"
#include <cmath>
#include <random>

struct RandomForest {
    int nTrees, maxDepth;
    std::vector<DecisionTree> trees;
    std::vector<std::vector<int>> oobMask;      // qué muestras quedaron fuera de cada árbol

    void fit(const std::vector<Vec>& X, const std::vector<int>& y, unsigned seed = 7) {
        std::mt19937 rng(seed);
        size_t N = X.size();
        int mtry = std::max(1, (int)std::round(std::sqrt((double)X[0].size())));  // √d
        std::uniform_int_distribution<size_t> pick(0, N - 1);
        for (int t = 0; t < nTrees; ++t) {
            std::vector<int> idx, inBag(N, 0);
            for (size_t i = 0; i < N; ++i) { size_t k = pick(rng); idx.push_back(k); inBag[k] = 1; }
            DecisionTree tree{maxDepth, 2, mtry};
            tree.fit(X, y, idx, rng());
            trees.push_back(std::move(tree));
            oobMask.push_back(inBag);
        }
    }

    int predict(const Vec& x) const {
        std::map<int, int> votes;
        for (auto& t : trees) votes[t.predict(x)]++;
        return std::max_element(votes.begin(), votes.end(),
                                [](auto& a, auto& b) { return a.second < b.second; })->first;
    }

    // Error out-of-bag: cada muestra sólo la votan los árboles que NO la vieron (~36.8%)
    double oobAccuracy(const std::vector<Vec>& X, const std::vector<int>& y) const {
        int ok = 0, total = 0;
        for (size_t i = 0; i < X.size(); ++i) {
            std::map<int, int> v;
            for (size_t t = 0; t < trees.size(); ++t) if (!oobMask[t][i]) v[trees[t].predict(X[i])]++;
            if (v.empty()) continue;
            int p = std::max_element(v.begin(), v.end(), [](auto& a, auto& b) { return a.second < b.second; })->first;
            ok += p == y[i]; ++total;
        }
        return double(ok) / total;
    }
};

Gradient Boosting

Árboles pequeños añadidos uno tras otro, cada uno corrigiendo lo que los anteriores aún fallan. El estado del arte en datos tabulares.

Para qué sirve

  • Competencias y producción con datos tabulares (XGBoost, LightGBM, CatBoost).
  • Ranking, riesgo de crédito, predicción de demanda.
  • Cualquier pérdida diferenciable: regresión, clasificación, cuantiles.

Por qué funciona

Es descenso de gradiente en el espacio de funciones. El modelo actual F tiene un gradiente de pérdida en cada punto; un árbol nuevo se ajusta a ese gradiente negativo y se suma con un paso pequeño η. Con MSE el gradiente negativo es el residuo, así que cada árbol aprende literalmente lo que falta. A diferencia de Random Forest, aquí se reduce el sesgo: árboles poco profundos (sesgados) se van sumando hasta formar un modelo flexible. Un η pequeño con más árboles generaliza mejor.

Fórmulas

Inicio
F₀(x) = argminc Σ L(yi, c) (la media con MSE)
Pseudo-residuo
rim = −∂L(yi, F(xi)) / ∂F
Actualización
Fm(x) = Fm−1(x) + η · hm(x)
Con MSE
ri = yi − F(xi)

Qué entra y qué sale

Entra
X, y
pérdida L
M, η
Gradient Boostingárbol sobre residuos, sumar, repetir
Sale
F(x) = F₀ + η Σ hm(x)

Flujo de cálculo

  1. Inicializar con una constante (media o log-odds).
  2. Calcular los pseudo-residuos de cada muestra.
  3. Ajustar un árbol pequeño a los residuos.
  4. Sumarlo al modelo multiplicado por η.
  5. Repetir M veces, con early stopping sobre validación.

Hiperparámetros

learning_rate η
0.01–0.3; más bajo requiere más árboles.
n_estimators
Usar early stopping.
max_depth
3–8 típicamente.
subsample
Fracción de filas por árbol (stochastic GB).

Costo: O(M · costo de un árbol). LightGBM usa histogramas para acelerar.

Cuidado con

  • Sobreajusta si se añaden árboles sin early stopping.
  • Es secuencial: entrena más lento que Random Forest, aunque las librerías lo paralelizan por feature.

// Gradient Boosting para regresión (pérdida MSE) con stumps (árboles de 1 corte)
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <vector>
using Vec = std::vector<double>;

struct Stump { int f; double thr, left, right; };

// Ajusta el mejor stump a los residuos r minimizando el error cuadrático
Stump fitStump(const std::vector<Vec>& X, const Vec& r) {
    Stump best{0, 0, 0, 0}; double bestErr = 1e300;
    size_t N = X.size(), d = X[0].size();
    for (size_t f = 0; f < d; ++f) {
        std::vector<size_t> o(N);
        for (size_t i = 0; i < N; ++i) o[i] = i;
        std::sort(o.begin(), o.end(), [&](size_t a, size_t b) { return X[a][f] < X[b][f]; });
        double sumL = 0, sqL = 0, sumT = 0, sqT = 0;
        for (double v : r) { sumT += v; sqT += v * v; }
        for (size_t k = 0; k + 1 < N; ++k) {           // barrido con sumas acumuladas O(N)
            double v = r[o[k]]; sumL += v; sqL += v * v;
            if (X[o[k]][f] == X[o[k + 1]][f]) continue;
            double nL = k + 1, nR = N - nL, sumR = sumT - sumL;
            double err = (sqL - sumL * sumL / nL) + ((sqT - sqL) - sumR * sumR / nR);
            if (err < bestErr) {
                bestErr = err;
                best = {(int)f, 0.5 * (X[o[k]][f] + X[o[k + 1]][f]), sumL / nL, sumR / nR};
            }
        }
    }
    return best;
}

struct GradientBoosting {
    int nEstimators; double lr;
    double f0 = 0; std::vector<Stump> stumps;

    double predict(const Vec& x) const {
        double y = f0;
        for (auto& s : stumps) y += lr * (x[s.f] <= s.thr ? s.left : s.right);
        return y;
    }

    void fit(const std::vector<Vec>& X, const Vec& y) {
        for (double v : y) f0 += v / y.size();          // F₀ = media
        Vec F(y.size(), f0);
        for (int m = 0; m < nEstimators; ++m) {
            Vec r(y.size());
            for (size_t i = 0; i < y.size(); ++i) r[i] = y[i] - F[i];   // −∂L/∂F = residuo (MSE)
            Stump s = fitStump(X, r);
            stumps.push_back(s);
            for (size_t i = 0; i < y.size(); ++i) F[i] += lr * (X[i][s.f] <= s.thr ? s.left : s.right);
            if (m % 60 == 0) {
                double mse = 0;
                for (size_t i = 0; i < y.size(); ++i) mse += (y[i] - F[i]) * (y[i] - F[i]) / y.size();
                std::printf("árbol %3d  MSE=%.4f\n", m, mse);
            }
        }
    }
};

Reducción de dimensionalidad

PCA: reducción de dimensionalidad con la covarianza

Rotar los datos a las direcciones de máxima varianza y quedarse con las primeras. Comprime, visualiza y elimina redundancia.

Para qué sirve

  • Visualizar datos de alta dimensión en 2D o 3D.
  • Comprimir features correlacionadas antes de otro modelo.
  • Eliminar ruido reconstruyendo con pocas componentes.
  • Whitening / decorrelación.

Por qué funciona

La matriz de covarianza resume cómo varían y covarían las features. Sus vectores propios son direcciones ortogonales y su valor propio es la varianza de los datos proyectados en esa dirección. Ordenarlos de mayor a menor y quedarse con los k primeros conserva la máxima varianza posible con k dimensiones, y equivale a minimizar el error de reconstrucción. En la escena 3D los datos casi viven en un plano: proyectarlos sobre PC1-PC2 pierde muy poco porque la varianza en PC3 es mínima.

Fórmulas

Covarianza
C = (1/(n−1)) Xc⊤Xc
Problema propio
Cvk = λk vk, λ₁ ≥ λ₂ ≥ … ≥ λd
Proyección
Z = Xc Wk, Wk = [v₁ … vk]
Varianza explicada
λk / Σj λj
Vía SVD
Xc = UΣV⊤, λk = σk²/(n−1)

Qué entra y qué sale

Entra
X (n × d)
k
PCAcentrar → C → eigen → proyectar
Sale
Z (n × k)
componentes W (d × k)
varianza explicada

Flujo de cálculo

  1. Centrar cada feature (y estandarizar si tienen unidades distintas).
  2. Calcular la matriz de covarianza d × d.
  3. Obtener vectores y valores propios (o SVD de Xc, más estable).
  4. Ordenar por valor propio descendente.
  5. Elegir k por varianza acumulada (p. ej. 95%) o por el codo.
  6. Proyectar: Z = XcWk.

Hiperparámetros

n_components
Entero o fracción de varianza a retener.
whiten
Escalar componentes a varianza 1.

Costo: Covarianza + eigen: O(nd² + d³). SVD truncada aleatoria para datos grandes.

Cuidado con

  • Es lineal: estructuras curvas necesitan t-SNE, UMAP o Kernel PCA.
  • Sin estandarizar, la feature con más varianza domina.
  • Las componentes son combinaciones de features: se pierde interpretabilidad.

// PCA: centrar → matriz de covarianza → eigenvectores (power iteration + deflación) → proyectar
#include <cmath>
#include <cstdio>
#include <random>
#include <vector>
using Vec = std::vector<double>;
using Mat = std::vector<Vec>;

Vec matVec(const Mat& A, const Vec& v) {
    Vec r(A.size(), 0.0);
    for (size_t i = 0; i < A.size(); ++i) for (size_t j = 0; j < v.size(); ++j) r[i] += A[i][j] * v[j];
    return r;
}
double dot(const Vec& a, const Vec& b) { double s = 0; for (size_t i = 0; i < a.size(); ++i) s += a[i] * b[i]; return s; }

struct PCA {
    int k; Vec mean, eigenvalues; Mat components;  // components[c] = vector unitario

    void fit(const Mat& X) {
        size_t n = X.size(), d = X[0].size();
        mean.assign(d, 0.0);
        for (auto& r : X) for (size_t j = 0; j < d; ++j) mean[j] += r[j] / n;
        Mat C(d, Vec(d, 0.0));                                   // C = XcᵀXc / (n−1)
        for (auto& r : X)
            for (size_t a = 0; a < d; ++a)
                for (size_t b = 0; b < d; ++b) C[a][b] += (r[a] - mean[a]) * (r[b] - mean[b]) / (n - 1);

        std::mt19937 rng(0); std::normal_distribution<double> G(0, 1);
        for (int c = 0; c < k; ++c) {
            Vec v(d); for (double& x : v) x = G(rng);
            for (int it = 0; it < 500; ++it) {                   // v ← Cv / ||Cv||
                Vec w = matVec(C, v);
                double nrm = std::sqrt(dot(w, w));
                for (size_t j = 0; j < d; ++j) v[j] = w[j] / nrm;
            }
            double lambda = dot(v, matVec(C, v));                // cociente de Rayleigh
            for (size_t a = 0; a < d; ++a)                       // deflación: C ← C − λvvᵀ
                for (size_t b = 0; b < d; ++b) C[a][b] -= lambda * v[a] * v[b];
            components.push_back(v); eigenvalues.push_back(lambda);
        }
    }

    Mat transform(const Mat& X) const {                         // Z = (X − μ) Wₖ
        Mat Z;
        for (auto& r : X) {
            Vec z(k);
            for (int c = 0; c < k; ++c) for (size_t j = 0; j < r.size(); ++j) z[c] += (r[j] - mean[j]) * components[c][j];
            Z.push_back(z);
        }
        return Z;
    }
};

K-Means

Agrupar los datos en K clusters alternando dos pasos: asignar cada punto al centro más cercano y mover cada centro a la media de su grupo.

Para qué sirve

  • Segmentación de clientes, compresión de colores, cuantización vectorial.
  • Inicialización de otros modelos (GMM).
  • Crear features (distancia a cada centroide).

Por qué funciona

Minimiza la inercia: la suma de distancias al cuadrado de cada punto a su centroide. Con los centros fijos, asignar cada punto al más cercano es óptimo; con las asignaciones fijas, la media es el punto que minimiza la suma de distancias cuadradas. Cada paso nunca aumenta la inercia, así que el algoritmo converge, aunque sólo a un mínimo local. k-means++ elige centros iniciales separados y mejora mucho el resultado. Supone clusters esféricos de tamaño parecido.

Cuidado con

  • Falla con clusters alargados, de densidad distinta o no convexos (usa DBSCAN o GMM).
  • Sensible a outliers: la media se desplaza hacia ellos.

// K-Means (algoritmo de Lloyd) con inicialización k-means++
#include <cmath>
#include <cstdio>
#include <limits>
#include <random>
#include <vector>
using Vec = std::vector<double>;

double dist2(const Vec& a, const Vec& b) {
    double s = 0;
    for (size_t i = 0; i < a.size(); ++i) s += (a[i] - b[i]) * (a[i] - b[i]);
    return s;
}

struct KMeans {
    int k; std::vector<Vec> C; std::vector<int> labels; double inertia = 0;

    // k-means++: el siguiente centro se elige con probabilidad ∝ D(x)²
    void initPlusPlus(const std::vector<Vec>& X, std::mt19937& rng) {
        std::uniform_int_distribution<size_t> U(0, X.size() - 1);
        C = {X[U(rng)]};
        while ((int)C.size() < k) {
            Vec D(X.size());
            for (size_t i = 0; i < X.size(); ++i) {
                D[i] = std::numeric_limits<double>::max();
                for (auto& c : C) D[i] = std::min(D[i], dist2(X[i], c));
            }
            std::discrete_distribution<size_t> pick(D.begin(), D.end());
            C.push_back(X[pick(rng)]);
        }
    }

    void fit(const std::vector<Vec>& X, int maxIter = 100, unsigned seed = 0) {
        std::mt19937 rng(seed);
        initPlusPlus(X, rng);
        size_t d = X[0].size();
        labels.assign(X.size(), -1);
        for (int it = 0; it < maxIter; ++it) {
            bool changed = false; inertia = 0;
            for (size_t i = 0; i < X.size(); ++i) {           // Paso E: asignar al centro más cercano
                int best = 0; double bd = dist2(X[i], C[0]);
                for (int c = 1; c < k; ++c) { double t = dist2(X[i], C[c]); if (t < bd) { bd = t; best = c; } }
                if (labels[i] != best) { labels[i] = best; changed = true; }
                inertia += bd;
            }
            std::vector<Vec> sum(k, Vec(d, 0)); std::vector<int> cnt(k, 0);
            for (size_t i = 0; i < X.size(); ++i) {           // Paso M: centro = media del grupo
                cnt[labels[i]]++;
                for (size_t j = 0; j < d; ++j) sum[labels[i]][j] += X[i][j];
            }
            for (int c = 0; c < k; ++c) if (cnt[c]) for (size_t j = 0; j < d; ++j) C[c][j] = sum[c][j] / cnt[c];
            std::printf("iter %d  inercia=%.3f\n", it, inertia);
            if (!changed) break;                              // convergió
        }
    }
};

DBSCAN

Clusters como regiones densas separadas por zonas vacías. Encuentra formas arbitrarias, no necesita K y marca el ruido.

Para qué sirve

  • Clusters de forma irregular (geografía, trayectorias).
  • Detección de anomalías: lo que queda como ruido.
  • Cuando no se sabe cuántos grupos hay.

Por qué funciona

Un punto es núcleo si tiene al menos minPts vecinos dentro de un radio ε. Dos núcleos dentro de ε uno del otro pertenecen al mismo cluster, y la relación se propaga como un incendio por la región densa. Los puntos que no son núcleo pero caen cerca de uno son borde; los demás son ruido. Como el cluster se define por conectividad y no por distancia a un centro, puede tener cualquier forma, como las dos lunas de la animación.

Fórmulas

Vecindad
Nε(p) = { q : ‖p − q‖ ≤ ε }
Núcleo
|Nε(p)| ≥ minPts
Alcanzable
q ∈ Nε(p) con p núcleo ⇒ mismo cluster

Qué entra y qué sale

Entra

Sale
etiqueta por punto (−1 = ruido)

Flujo de cálculo

  1. Para cada punto no visitado, buscar sus vecinos dentro de ε.
  2. Si tiene menos de minPts, marcarlo como ruido (por ahora).
  3. Si es núcleo, abrir un cluster nuevo y meter sus vecinos en una cola.
  4. Sacar de la cola: asignar al cluster; si también es núcleo, encolar sus vecinos.
  5. Cuando la cola se vacía, pasar al siguiente punto sin visitar.

Hiperparámetros

eps ε
Radio; elegir con el codo del gráfico de distancia al k-ésimo vecino.
min_samples
Regla práctica: 2·d.

Costo: O(n log n) con índice espacial; O(n²) en fuerza bruta.

Cuidado con

  • Un solo ε no sirve si los clusters tienen densidades muy distintas (usa HDBSCAN).
  • Escala las features: ε es una distancia.

Implementación

// DBSCAN: clustering por densidad. Encuentra formas arbitrarias y marca ruido (−1)
#include <cmath>
#include <cstdio>
#include <queue>
#include <random>
#include <vector>
using Vec = std::vector<double>;

struct DBSCAN {
    double eps; int minPts;
    std::vector<int> labels;    // −2 = sin visitar, −1 = ruido, ≥0 = id de cluster

    std::vector<int> neighbors(const std::vector<Vec>& X, int i) const {
        std::vector<int> out;
        for (size_t j = 0; j < X.size(); ++j) {
            double dx = X[i][0] - X[j][0], dy = X[i][1] - X[j][1];
            if (dx * dx + dy * dy <= eps * eps) out.push_back(j);   // incluye al propio i
        }
        return out;
    }

    int fit(const std::vector<Vec>& X) {
        labels.assign(X.size(), -2);
        int cluster = 0;
        for (size_t i = 0; i < X.size(); ++i) {
            if (labels[i] != -2) continue;
            auto nb = neighbors(X, i);
            if ((int)nb.size() < minPts) { labels[i] = -1; continue; }  // ruido (por ahora)
            labels[i] = cluster;                                          // i es punto núcleo
            std::queue<int> q;
            for (int j : nb) q.push(j);
            while (!q.empty()) {                                          // expandir por BFS
                int j = q.front(); q.pop();
                if (labels[j] == -1) labels[j] = cluster;                 // ruido → borde
                if (labels[j] != -2) continue;
                labels[j] = cluster;
                auto nb2 = neighbors(X, j);
                if ((int)nb2.size() >= minPts) for (int t : nb2) q.push(t);  // j también es núcleo
            }
            ++cluster;
        }
        return cluster;
    }
};

Clustering jerárquico aglomerativo

Empezar con cada punto como su propio cluster y fusionar repetidamente los dos más cercanos. El resultado es un árbol: el dendrograma.

Para qué sirve

  • Explorar la estructura a varios niveles de granularidad.
  • Taxonomías, filogenia, agrupar documentos.
  • Cuando quieres decidir K después de ver los datos.

Por qué funciona

El dendrograma registra cada fusión y la distancia a la que ocurrió. Cortarlo a una altura da una partición; cortes más bajos dan más clusters. Todo depende de cómo se mide la distancia entre grupos: single (el par más cercano) forma cadenas largas, complete (el par más lejano) da grupos compactos, average es intermedio y Ward fusiona lo que menos aumenta la varianza interna, parecido a K-Means. Saltos grandes en la altura de fusión indican clusters naturales.

Fórmulas

Single
d(A, B) = mina∈A, b∈B d(a, b)
Complete
d(A, B) = max d(a, b)
Average
d(A, B) = (1/|A||B|) Σ Σ d(a, b)
Ward
Δ = (|A||B| / (|A|+|B|)) ‖μA − μB‖²

  1. Calcular la matriz de distancias entre todos los puntos.
  2. Buscar el par de clusters más cercano.
  3. Fusionarlos y registrar la altura en el dendrograma.
  4. Actualizar distancias del nuevo cluster (Lance-Williams).
  5. Repetir hasta tener un solo cluster.

Cuidado con

  • Memoria O(n²): inviable más allá de unas decenas de miles de puntos.
  • Las fusiones son definitivas: un error temprano no se corrige.

// Clustering jerárquico aglomerativo (enlace promedio / single / complete) → dendrograma
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <limits>
#include <vector>
using Vec = std::vector<double>;

enum class Link { Single, Complete, Average };

struct Merge { int a, b; double dist; int size; };   // formato tipo scipy "linkage"

std::vector<Merge> agglomerative(const std::vector<Vec>& X, Link link) {
    int n = X.size();
    // D[i][j] = distancia entre clusters i y j (se actualiza con Lance-Williams)
    std::vector<Vec> D(2 * n, Vec(2 * n, 0));
    for (int i = 0; i < n; ++i) for (int j = 0; j < n; ++j) {
        double s = 0; for (size_t k = 0; k < X[i].size(); ++k) s += (X[i][k] - X[j][k]) * (X[i][k] - X[j][k]);
        D[i][j] = std::sqrt(s);
    }
    std::vector<int> active, size(2 * n, 1);
    for (int i = 0; i < n; ++i) active.push_back(i);
    std::vector<Merge> merges;
    int next = n;
    while (active.size() > 1) {
        double best = std::numeric_limits<double>::max(); int ia = 0, ib = 1;
        for (size_t p = 0; p < active.size(); ++p)              // par más cercano: O(m²)
            for (size_t q = p + 1; q < active.size(); ++q)
                if (D[active[p]][active[q]] < best) { best = D[active[p]][active[q]]; ia = p; ib = q; }
        int a = active[ia], b = active[ib];
        size[next] = size[a] + size[b];
        for (int c : active) if (c != a && c != b) {
            double d = link == Link::Single   ? std::min(D[a][c], D[b][c])
                     : link == Link::Complete ? std::max(D[a][c], D[b][c])
                     : (size[a] * D[a][c] + size[b] * D[b][c]) / size[next];
            D[next][c] = D[c][next] = d;
        }
        merges.push_back({a, b, best, size[next]});
        active.erase(active.begin() + ib); active.erase(active.begin() + ia);
        active.push_back(next++);
    }
    return merges;
}

// Cortar el dendrograma: deshacer las últimas k−1 fusiones
std::vector<int> cutTree(const std::vector<Merge>& M, int n, int k) {
    std::vector<int> parent(2 * n);
    for (int i = 0; i < 2 * n; ++i) parent[i] = i;
    for (int m = 0; m < n - k; ++m) parent[M[m].a] = parent[M[m].b] = n + m;
    std::vector<int> lab(n);
    for (int i = 0; i < n; ++i) { int r = i; while (parent[r] != r) r = parent[r]; lab[i] = r; }
    return lab;
}

int main() {
    std::vector<Vec> X = {{1, 1}, {1.2, 1.1}, {5, 5}, {5.1, 4.8}, {9, 1}, {9.2, 1.3}, {5.3, 5.2}};
    auto M = agglomerative(X, Link::Average);
    for (auto& m : M) std::printf("fusiona %d + %d  dist=%.3f  tamaño=%d\n", m.a, m.b, m.dist, m.size);
    auto lab = cutTree(M, X.size(), 3);
    for (size_t i = 0; i < X.size(); ++i) std::printf("p%zu→c%d ", i, lab[i]);
    std::printf("\n");
}

Mezcla de gaussianas (GMM) y EM

Modelar los datos como una suma de K gaussianas. Cada punto pertenece a cada cluster con cierta probabilidad.

Para qué sirve

  • Clustering suave con clusters elípticos de distinto tamaño.
  • Estimación de densidad y detección de anomalías.
  • Modelos de voz y de fondo en visión clásica.

Por qué funciona

K-Means asigna cada punto a un solo cluster y supone esferas; GMM generaliza ambas cosas. Si supiéramos de qué gaussiana viene cada punto, estimar sus parámetros sería trivial; si supiéramos los parámetros, calcular esa pertenencia también. EM alterna: el paso E calcula responsabilidades (probabilidad de cada componente para cada punto) y el paso M reestima pesos, medias y covarianzas con esas responsabilidades como pesos. La log-verosimilitud nunca baja entre iteraciones.

// Gaussian Mixture Model 1D con Expectation-Maximization
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <random>
#include <vector>
using Vec = std::vector<double>;

double normalPdf(double x, double mu, double var) {
    return std::exp(-(x - mu) * (x - mu) / (2 * var)) / std::sqrt(2 * M_PI * var);
}

struct GMM1D {
    int K; Vec pi, mu, var;

    void fit(const Vec& x, int iters = 100) {
        size_t N = x.size();
        pi.assign(K, 1.0 / K); var.assign(K, 1.0); mu.resize(K);
        double lo = *std::min_element(x.begin(), x.end()), hi = *std::max_element(x.begin(), x.end());
        for (int k = 0; k < K; ++k) mu[k] = lo + (hi - lo) * (k + 0.5) / K;
        std::vector<Vec> r(N, Vec(K));
        double prevLL = -1e300;
        for (int it = 0; it < iters; ++it) {
            double ll = 0;
            for (size_t i = 0; i < N; ++i) {             // E: responsabilidades γ_ik
                double s = 0;
                for (int k = 0; k < K; ++k) s += r[i][k] = pi[k] * normalPdf(x[i], mu[k], var[k]);
                for (int k = 0; k < K; ++k) r[i][k] /= s;
                ll += std::log(s);
            }
            for (int k = 0; k < K; ++k) {                // M: re-estimar π, μ, σ² ponderados por γ
                double Nk = 0, m = 0, v = 0;
                for (size_t i = 0; i < N; ++i) { Nk += r[i][k]; m += r[i][k] * x[i]; }
                m /= Nk;
                for (size_t i = 0; i < N; ++i) v += r[i][k] * (x[i] - m) * (x[i] - m);
                pi[k] = Nk / N; mu[k] = m; var[k] = v / Nk + 1e-6;
            }
            if (it % 10 == 0) std::printf("iter %2d  log-verosimilitud=%.3f\n", it, ll);
            if (std::fabs(ll - prevLL) < 1e-6) break;    // EM nunca disminuye la LL
            prevLL = ll;
        }
    }
};

Redes neuronales

Perceptrón multicapa (MLP) y backpropagation

Capas de neuronas con activaciones no lineales, entrenadas propagando el error hacia atrás con la regla de la cadena.

Para qué sirve

  • Problemas no lineales donde los modelos lineales no alcanzan.
  • Bloque que aparece dentro de CNNs, RNNs y Transformers.
  • Aproximar cualquier función continua (teorema de aproximación universal).

Por qué funciona

Una capa es una transformación lineal seguida de una no linealidad. Sin la no linealidad, apilar capas sería un único modelo lineal. Las capas ocultas aprenden a deformar el espacio hasta que las clases se separan con una recta: XOR, imposible para el perceptrón, se resuelve con una capa oculta. Backprop calcula el gradiente de la pérdida respecto a cada peso reutilizando los gradientes de la capa siguiente: δ de la capa l = (W⊤δ de la capa l+1) ⊙ f′(z). Así el costo del gradiente es el mismo orden que el del forward.

Fórmulas

Forward
z(l) = W(l)a(l−1) + b(l); a(l) = f(z(l))
Salida
p = softmax(z(L)); L = −log py
Delta de salida
δ(L) = p − onehot(y)
Backprop
δ(l) = (W(l+1)⊤ δ(l+1)) ⊙ f′(z(l))
Gradientes
∂L/∂W(l) = δ(l) a(l−1)⊤; ∂L/∂b(l) = δ(l)
ReLU
f(z) = max(0, z); f′(z) = 𝟙[z > 0]

Flujo de cálculo

  1. Inicializar pesos (He para ReLU, Xavier para tanh) y sesgos en 0.
  2. Forward: capa por capa, guardar z y a.
  3. Calcular la pérdida con softmax + entropía cruzada.
  4. Backward: δ de salida = p − y; propagar δ hacia atrás multiplicando por W⊤ y f′.
  5. Acumular ∂W = δ·a⊤ sobre el mini-batch.
  6. Actualizar con SGD/Adam y repetir por épocas.

Cuidado con

  • Escala las entradas: las redes son muy sensibles a la escala.
  • Gradientes que desaparecen o explotan: inicialización correcta, normalización, ReLU.
  • Para datos tabulares, Gradient Boosting suele ganar a un MLP.

// MLP desde cero: capas densas, ReLU, softmax + entropía cruzada, backprop y SGD
// Arquitectura de ejemplo: 2 → 16 → 16 → 2, resolviendo XOR / espirales
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <random>
#include <vector>
using Vec = std::vector<double>;
using Mat = std::vector<Vec>;

struct Dense {
    Mat W; Vec b;            // W: out × in
    Vec x, z;                // caché del forward (entrada y pre-activación)
    Mat dW; Vec db;

    Dense(int in, int out, std::mt19937& rng) : W(out, Vec(in)), b(out, 0.0), dW(out, Vec(in, 0.0)), db(out, 0.0) {
        std::normal_distribution<double> G(0, std::sqrt(2.0 / in));      // inicialización He
        for (auto& r : W) for (double& w : r) w = G(rng);
    }
    Vec forward(const Vec& in) {                                       // z = Wx + b
        x = in; z = b;
        for (size_t o = 0; o < W.size(); ++o) for (size_t i = 0; i < in.size(); ++i) z[o] += W[o][i] * in[i];
        return z;
    }
    Vec backward(const Vec& dz) {                                      // acumula dW, db; devuelve dx
        Vec dx(x.size(), 0.0);
        for (size_t o = 0; o < W.size(); ++o) {
            db[o] += dz[o];
            for (size_t i = 0; i < x.size(); ++i) { dW[o][i] += dz[o] * x[i]; dx[i] += W[o][i] * dz[o]; }
        }
        return dx;
    }
    void step(double lr, int batch) {
        for (size_t o = 0; o < W.size(); ++o) {
            b[o] -= lr * db[o] / batch; db[o] = 0;
            for (size_t i = 0; i < W[o].size(); ++i) { W[o][i] -= lr * dW[o][i] / batch; dW[o][i] = 0; }
        }
    }
};

Vec relu(const Vec& z) { Vec a(z); for (double& v : a) v = std::max(0.0, v); return a; }
Vec reluBack(const Vec& da, const Vec& z) { Vec d(da); for (size_t i = 0; i < d.size(); ++i) if (z[i] <= 0) d[i] = 0; return d; }
Vec softmax(const Vec& z) {
    double m = *std::max_element(z.begin(), z.end()), s = 0; Vec p(z.size());
    for (size_t i = 0; i < z.size(); ++i) s += p[i] = std::exp(z[i] - m);
    for (double& v : p) v /= s;
    return p;
}

struct MLP {
    std::vector<Dense> layers;
    MLP(const std::vector<int>& sizes, unsigned seed = 0) {
        std::mt19937 rng(seed);
        for (size_t l = 0; l + 1 < sizes.size(); ++l) layers.emplace_back(sizes[l], sizes[l + 1], rng);
    }
    Vec forward(Vec a) {
        for (size_t l = 0; l < layers.size(); ++l) {
            a = layers[l].forward(a);
            if (l + 1 < layers.size()) a = relu(a);                     // sin ReLU en la última capa
        }
        return softmax(a);
    }
    double trainStep(const Vec& x, int y) {
        Vec p = forward(x);
        Vec d = p; d[y] -= 1.0;                                         // ∂CE/∂z = p − onehot(y)
        for (int l = layers.size() - 1; l >= 0; --l) {
            d = layers[l].backward(d);
            if (l > 0) d = reluBack(d, layers[l - 1].z);                // regla de la cadena
        }
        return -std::log(p[y] + 1e-12);
    }
    void fit(const Mat& X, const std::vector<int>& y, int epochs, int batch, double lr) {
        std::mt19937 rng(1);
        std::vector<int> idx(X.size());
        for (size_t i = 0; i < idx.size(); ++i) idx[i] = i;
        for (int e = 0; e < epochs; ++e) {
            std::shuffle(idx.begin(), idx.end(), rng);
            double loss = 0;
            for (size_t s = 0; s < idx.size(); s += batch) {
                int bs = std::min<int>(batch, idx.size() - s);
                for (int k = 0; k < bs; ++k) loss += trainStep(X[idx[s + k]], y[idx[s + k]]);
                for (auto& L : layers) L.step(lr, bs);
            }
            if (e % 100 == 0) std::printf("época %3d  loss=%.4f\n", e, loss / X.size());
        }
    }
    int predict(const Vec& x) { Vec p = forward(x); return std::max_element(p.begin(), p.end()) - p.begin(); }
};

int main() {
    Mat X; std::vector<int> y;
    std::mt19937 rng(3); std::normal_distribution<double> G(0, 0.15);
    for (int i = 0; i < 400; ++i) {                       // XOR con ruido en 4 cuadrantes
        double a = (i & 1) ? 1 : -1, b = (i & 2) ? 1 : -1;
        X.push_back({a + G(rng), b + G(rng)});
        y.push_back(a * b < 0);
    }
    MLP net({2, 16, 16, 2});
    net.fit(X, y, 400, 32, 0.1);
    int ok = 0; for (size_t i = 0; i < X.size(); ++i) ok += net.predict(X[i]) == y[i];
    std::printf("accuracy=%.3f\n", ok / double(X.size()));
}

Evaluación

Matriz de confusión, precision, recall, F1 y ROC-AUC

Cómo medir un clasificador más allá de la accuracy, y cómo el umbral mueve el balance entre tipos de error.

Para qué sirve

  • Clases desbalanceadas (fraude, enfermedades raras), donde la accuracy engaña.
  • Elegir el umbral según el costo real de cada error.
  • Comparar modelos independientemente del umbral (AUC).

Por qué funciona

Al bajar el umbral el modelo dice «sí» más veces: atrapa más positivos (sube recall) pero también más falsos positivos (baja precision). La curva ROC dibuja TPR contra FPR para todos los umbrales; el AUC es la probabilidad de que un positivo al azar reciba más score que un negativo al azar. 0.5 es azar, 1 es perfecto. Con desbalance fuerte la curva precision-recall es más informativa que la ROC.

Recall (TPR)
R = TP / (TP + FN)
F1
F₁ = 2PR / (P + R)
FPR
FPR = FP / (FP + TN)
AUC
AUC = P(s+ > s−)

Flujo de cálculo

  1. Obtener scores (probabilidades) del modelo sobre el set de prueba.
  2. Fijar un umbral y convertir a predicciones.
  3. Contar TP, FP, TN, FN.
  4. Calcular precision, recall y F1.
  5. Barrer el umbral para trazar ROC y PR; integrar el área.
  6. Elegir el umbral que minimice el costo de negocio.

Hiperparámetros

umbral
No es un hiperparámetro del modelo, pero cambia todas las métricas salvo AUC.

Costo: O(n log n) para la ROC (ordenar scores).

Cuidado con

  • Multiclase: promedio macro (cada clase igual) vs weighted vs micro.
  • Nunca elijas el umbral sobre el set de prueba.

// Métricas de clasificación: matriz de confusión, precision, recall, F1, ROC y AUC
#include <algorithm>
#include <cstdio>
#include <vector>
using Vec = std::vector<double>;

struct Confusion { int tp = 0, fp = 0, tn = 0, fn = 0; };

Confusion confusion(const std::vector<int>& y, const Vec& score, double thr) {
    Confusion c;
    for (size_t i = 0; i < y.size(); ++i) {
        bool pred = score[i] >= thr;
        if (pred && y[i]) c.tp++; else if (pred && !y[i]) c.fp++;
        else if (!pred && !y[i]) c.tn++; else c.fn++;
    }
    return c;
}

double precision(const Confusion& c) { return c.tp + c.fp ? double(c.tp) / (c.tp + c.fp) : 0; }  // de lo que dije "sí", ¿cuánto era?
double recall(const Confusion& c)    { return c.tp + c.fn ? double(c.tp) / (c.tp + c.fn) : 0; }  // de lo que era "sí", ¿cuánto encontré?
double f1(const Confusion& c) { double p = precision(c), r = recall(c); return p + r ? 2 * p * r / (p + r) : 0; }

// Curva ROC: ordenar por score descendente y barrer el umbral; AUC por trapecios
double rocAuc(const std::vector<int>& y, const Vec& s, std::vector<std::pair<double, double>>* curve = nullptr) {
    std::vector<size_t> o(y.size());
    for (size_t i = 0; i < o.size(); ++i) o[i] = i;
    std::sort(o.begin(), o.end(), [&](size_t a, size_t b) { return s[a] > s[b]; });
    double P = 0, N = 0;
    for (int v : y) (v ? P : N) += 1;
    double tp = 0, fp = 0, prevTpr = 0, prevFpr = 0, auc = 0;
    if (curve) curve->push_back({0, 0});
    for (size_t k = 0; k < o.size(); ++k) {
        (y[o[k]] ? tp : fp) += 1;
        if (k + 1 < o.size() && s[o[k + 1]] == s[o[k]]) continue;    // empates: un solo punto
        double tpr = tp / P, fpr = fp / N;
        auc += (fpr - prevFpr) * (tpr + prevTpr) / 2;
        prevTpr = tpr; prevFpr = fpr;
        if (curve) curve->push_back({fpr, tpr});
    }
    return auc;   // = P(score de un positivo > score de un negativo)
}

int main() {
    std::vector<int> y = {1, 1, 0, 1, 0, 0, 1, 0, 1, 0};
    Vec s = {0.95, 0.85, 0.80, 0.70, 0.55, 0.45, 0.40, 0.30, 0.20, 0.10};
    for (double thr : {0.3, 0.5, 0.75}) {
        auto c = confusion(y, s, thr);
        std::printf("thr=%.2f  TP=%d FP=%d TN=%d FN=%d  P=%.2f R=%.2f F1=%.2f\n",
                    thr, c.tp, c.fp, c.tn, c.fn, precision(c), recall(c), f1(c));
    }
    std::printf("AUC=%.3f\n", rocAuc(y, s));
}

Validación cruzada k-fold

Estimar cómo se comportará el modelo con datos nuevos entrenando y evaluando k veces sobre particiones distintas.

Para qué sirve

  • Elegir hiperparámetros sin tocar el set de prueba.
  • Comparar modelos con una estimación más estable que un solo split.
  • Aprovechar todos los datos cuando son pocos.

Por qué funciona

Un solo split train/test depende de la suerte de qué muestras cayeron en cada lado. Con k-fold cada muestra se usa exactamente una vez para evaluar y k−1 veces para entrenar; el promedio de los k scores es más estable y su desviación indica cuánto varía. Todo el preprocesamiento (escalado, selección de features) debe ajustarse dentro de cada fold: si se ajusta con todos los datos antes de partir, la información de prueba se filtra al entrenamiento.

  • Datos agrupados (varios registros del mismo paciente) requieren GroupKFold.

// Validación cruzada k-fold genérica: estima el error de generalización
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <functional>
#include <numeric>
#include <random>
#include <vector>
using Vec = std::vector<double>;

// model(trainIdx, testIdx) → métrica en el fold de prueba
using Evaluator = std::function<double(const std::vector<int>&, const std::vector<int>&)>;

std::pair<double, double> crossValidate(int n, int k, Evaluator model, unsigned seed = 0) {
    std::vector<int> idx(n);
    std::iota(idx.begin(), idx.end(), 0);
    std::shuffle(idx.begin(), idx.end(), std::mt19937(seed));   // barajar ANTES de partir
    Vec scores;
    for (int f = 0; f < k; ++f) {
        int lo = f * n / k, hi = (f + 1) * n / k;                 // fold f = [lo, hi)
        std::vector<int> train, test;
        for (int i = 0; i < n; ++i) (i >= lo && i < hi ? test : train).push_back(idx[i]);
        scores.push_back(model(train, test));
        std::printf("fold %d  train=%zu test=%zu  score=%.4f\n", f, train.size(), test.size(), scores.back());
    }
    double m = std::accumulate(scores.begin(), scores.end(), 0.0) / k, v = 0;
    for (double s : scores) v += (s - m) * (s - m) / (k - 1);
    return {m, std::sqrt(v)};
}

int main() {
    // Datos y = 3x + 1 + ruido; modelo: regresión lineal simple; métrica: MSE
    std::mt19937 rng(0); std::normal_distribution<double> G(0, 1);
    Vec x, y;
    for (int i = 0; i < 100; ++i) { x.push_back(i / 10.0); y.push_back(3 * x.back() + 1 + G(rng)); }
    auto linreg = [&](const std::vector<int>& tr, const std::vector<int>& te) {
        double mx = 0, my = 0, sxy = 0, sxx = 0;
        for (int i : tr) { mx += x[i] / tr.size(); my += y[i] / tr.size(); }
        for (int i : tr) { sxy += (x[i] - mx) * (y[i] - my); sxx += (x[i] - mx) * (x[i] - mx); }
        double w = sxy / sxx, b = my - w * mx, mse = 0;
        for (int i : te) mse += (y[i] - (w * x[i] + b)) * (y[i] - (w * x[i] + b)) / te.size();
        return mse;
    };
    auto [mean, sd] = crossValidate(x.size(), 5, linreg);
    std::printf("MSE CV = %.4f ± %.4f\n", mean, sd);
}
